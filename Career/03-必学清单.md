# 03 · 必学清单

> 这一页取代 [[02-双轨学习排期]] 的 17 周表。那份排了 162 小时，你学不完，学完了也不一定用得上。  
> 这里只留**不学就完全干不下去**的：5 项，36 小时，约 8 周。

---

## 一、什么才算"不学不行"

三个条件同时成立，才进这张表。少一条就滚到"卡住再补"。

1. **现场会直接卡住**——不是"显得不专业"，是动作做不下去。
2. **卡住时没有替代方案**——查不到、绕不过、问 AI 也验不了。
3. **判错的代价不可逆**——数据拿错、定级定错、exp 打一晚上不响。

按这三条筛，你需要的只有五项。

---

## 二、五项必学

### 1. Windows 权限判据 · 12h

**不学就怎样**：提权 exp 打不响，你说不出缺哪一样。这是你知识栈里唯一的硬洞（Linux + Web，Windows 是空的）。

**材料**：[[Tech/操作系统/00-学习地图]] 的 M0–M5（Linux / Windows 双平台对照，每单元 75 分钟）。

**最少学这五条**：

| 判据                                                                                                              | 它决定什么                     |
| --------------------------------------------------------------------------------------------------------------- | ------------------------- |
| 令牌：主令牌 vs 模拟令牌；UAC 下管理员组拿到的是 **filtered token**（Medium）                                                         | "我是管理员"和"我有管理员权限"是两件事     |
| 完整性级别 Medium/High/System                                                                                        | DACL 通过了也未必能写——第二道门       |
| DACL 求值：**拒绝优先于允许**；组继承；所有者永远能改权限                                                                               | `Access is denied` 到底是谁挡的 |
| 六个特权：`SeDebug`（读任意进程）、`SeImpersonate`（借别人身份）、`SeBackup`/`SeRestore`（绕过 ACL 读写）、`SeTakeOwnership`、`SeLoadDriver` | `whoami /priv` 里那一行能不能用   |
| 服务与进程身份：服务账户是谁、`sc qc` 看什么                                                                                      | 服务劫持报得对不对                 |

**验收**：给 `whoami /priv` + `systeminfo` + 服务列表，30 分钟排出 3 条提权路径、按成功率排序、说出每条的前提失效点。

**不学**：进程调度、内存管理、文件系统、驱动开发。

---

### 2. 凭据与适用范围 · 6h

**不学就怎样**：抓到 hash 不知道能不能用、往哪用。这是你 Q4 已经栽过的洞。

**最少学这四条**：

- **存哪**：lsass（交互式凭据）、SAM（本地账户）、NTDS.dit（域）、DPAPI（浏览器/凭据管理器）、配置文件与脚本
- **谁能读**：lsass 要本地管理员 + `SeDebug`；SAM 要 SYSTEM；NTDS 要域控管理员
- **NTLM hash 能干什么**：PTH，不破解也能过认证。**不能干什么**：不能用于 Kerberos 服务认证
- **票据**：TGT 与 TGS 的区别；Kerberoast 打的是服务账户的 TGS，不是 TGT

**验收**：拿到一个 hash，说清它属于谁、能打哪几台、为什么打不了另外几台。

---

### 3. 日志与告警反推 · 8h

**不学就怎样**：你会看告警，但说不出它由什么触发。客户问"这条怎么来的"，你只能答"规则命中了"。

**材料**：同一条线的 M8（[[Tech/操作系统/S1/M8-导读-日志与审计]]），不另起一套。日志和权限是同一件事的两面，拆开学会变成两套半懂的模型。

**最少学这四块**：

| 块       | 最小内容                                                                                                        |
| ------- | ----------------------------------------------------------------------------------------------------------- |
| 关键事件 ID | 4624（看 **LogonType**，2/3/10 意义完全不同）、4625、4688（进程创建 + 命令行）、7045（服务安装）、4768/4769（Kerberos）、4720（建号）、1102（清日志） |
| Sysmon  | 事件 1 进程、3 网络、11 文件、13 注册表——四个够用                                                                             |
| 检测层次    | 用户态钩子 / ETW 与内核回调 / 行为规则。绕过要在同一层想                                                                           |
| 日志侧特征   | 编码后的命令行、异常父进程、服务二进制落在临时目录、短时间大量 4625                                                                        |

**验收**：任取你手上一条真实告警，说出触发它的具体行为 + 命中哪一层。**用真实日志，不用样本。**

---

### 4. 数据库两件事 · 6h

**不学就怎样**：拖库条数和数据边界判不准——你定级里的"体量"这一轴直接失真。

**只学两件事，不学 SQL 教程**：

- **权限模型**：MySQL 的 `user@host`（同一账号不同来源不同权限）、库级/表级/列级；SQL Server 的 login/user/schema 与 `sa`
- **体量与读写边界**：`count(*)` 与分页 total 才是实测，`information_schema.table_rows` 是估算**不能当证据**；`secure_file_priv`、`INTO OUTFILE`、`LOAD_FILE`；SQL Server 的 `xp_cmdshell`、`OPENROWSET`

外加半件事：**字段识别**——证件号、手机号、银行卡长什么样，校验位怎么算（你已经会，别丢）。

**不学**：SQL 语法教程、索引与优化、存储过程、备份恢复。`Tech/其它/关系型数据库.md` 是语法手册，查就行。

---

### 5. 密码学四组区分 · 4h

**不学就怎样**：把 hash 当"加了密的"——这句话你已经说过一次。判错一个串，后面的动作全错。

**只有四组区分**：

| 类别   | 特征                   | 能不能逆               |
| ---- | -------------------- | ------------------ |
| hash | 定长、单向、无密钥            | 不能逆，只能撞（撞得动撞不动看算法） |
| 加密   | 要密钥，可逆               | 有密钥就能解             |
| 编码   | 无密钥，公开规则（base64、URL） | **任何人可逆**，不提供任何保密  |
| 签名   | 验来源与完整性              | 不用于保密              |

再加三条：对称加密数据、非对称换密钥与签名；TLS 证书验的是"这个公钥属于这个域名"，不是"网站安全"；JWT 是三段 base64，**载荷不是加密**，`alg:none` 和弱密钥是常见洞。

**验收**：给一个串，30 秒判它是哪类、能不能逆、下一步该找什么。

**不学**：密码学数学、算法推导、国密体系细节。

## 五、8 周落地

每周一个主题，工作日 4.5h 学它，周末 5h 在靶场验证它。**不并行，不补课，学完就走。**

| 周   | 工作日                  | 周末验证                     |
| --- | -------------------- | ------------------------ |
| W1  | 令牌 + 完整性级别           | 靶场里制造一次"是管理员却被拒"，说清是哪个令牌 |
| W2  | DACL 求值 + 六个特权       | 给 3 台机器排提权路径（闸二），每台写失效点  |
| W3  | 服务与进程身份              | 验一次服务劫持，报得对或明确否掉         |
| W4  | 凭据存放点 + 适用范围         | 抓到一个 hash，写出它属于谁、能打哪几台   |
| W5  | NTLM / Kerberos / 票据 | 在域环境里区分 PTH 与票据滥用各能干什么   |
| W6  | 事件 ID + Sysmon       | 用自己手上的真实日志反推 3 条告警       |
| W7  | 检测层次 + 数据库两件事        | 靶场里从注入点算出能拿多少条           |
| W8  | 密码学四组 + 收口           | 给 10 个串分类，全对才过           |

**判据**：W2 的闸二做不出来，说明 W1 白学，回炉一周。**其余情况不回头。**
