# 多元思维格栅 · 总览

> **一句话**：手里有一批跨学科、且**真正懂**的模型，遇到陌生问题时能同时装上几片镜片去看，**看它们在哪里互相矛盾**。
>
> 名字借自芒格的 latticework of mental models。**这篇只讲：怎么建、怎么用、什么时候不灵。**

---

## 一、结构：四格，前三格就是你说的三领域

| 格 | 你原本的说法 | 它回答什么 | 卡片 |
|---|---|---|---|
| **格一 · 数学** | "量化分析世界，对复杂问题建模" | 这个量是多少？会怎么累积、怎么分布？ | M01–M06、M22 |
| **格二 · 逻辑学** | "从已知推导未知" | 我这个"推"有效吗？结论被证据保证了吗？ | L01–L06 |
| **格三 · 广义物理学** | "物理、化学、生物，客观世界的规律" | 这个设想在世界这一层过得去吗？代价必然出现在哪？ | M07–M16 |
| **格四 · 主体与制度** | （补的，理由见下） | 明知该做的事，为什么没人做？ | M17–M26 |

**为什么补第四格**：前三个格处理"客观世界"和"我如何正确推导"，但有一类问题它们全部失明——**制度落不了地、供应商糊弄、方案改不动、共识是假的**。这类问题里对象**会对你做出反应**，不遵守固定规律。芒格本人的格栅里，心理学与经济学占比很大，正是这个原因。所以它不是外加的，是原型的组成部分。

**前三格回答"对不对"，第四格回答"会不会发生"。**

---

## 二、它为什么不是收藏夹

「模型清单」最容易变成名言集——存 100 个，一个也用不出来。区别只有一条：

| 收藏夹 | 格栅 |
|---|---|
| 一条模型 = 一句概括 | 一条模型 = **内核 + 它盯什么 + 怎么用 + 边界** |
| 用来复述 | 用来在**有信号时被调用** |
| 追求数量 | 追求**交叉验证**：同一件事至少上两片，且跨格 |
| 存的是"谁说过" | 存的是"它在哪里不成立" |

本库每条卡片**必须有「边界」**，且要写出"它会把你带向哪个方向的错误"。写不出边界的卡片不许进库（同 H4）。

**为什么"维基都能查到"还能入库**：单条查得到，但「什么时候该调哪几条、它们互相打架时怎么办」查不到。**格栅的价值不在条目，在索引和冲突。**

---

## 三、卡片格式（四段，缺一段不许进库）

```
内核       一句话讲清机制。不许出现"很重要""要注意"
它盯什么    这类模型专门解释什么现象（写现象，不写名词）
怎么用      1-3 步，可执行。写不出步骤 = 还没懂
边界       它在什么情况下会误导你，且往哪个方向误导
```

**第四段三条硬要求**：写出**错误的方向**（高估还是低估）、给出**一个反例场景**、不许写"具体问题具体分析"这类免责。

---

## 四、怎么用：三步，且必须"上多片"

**一次只用一个模型，等于拿锤子找钉子。**

| 步 | 动作 | 时间 |
|---|---|---|
| 1 | **认出信号**：这件事属于哪一类？（趋势 / 数字可疑 / 系统出问题 / 人不配合 / 该不该投 / 我的推理可能错了） | 30 秒 |
| 2 | **上 2–3 片**：去 [[06-问题到模型]] 查对应行，**尽量跨格**（一片数学 + 一片逻辑 + 一片物理，比三片数学强得多） | 1 分钟 |
| 3 | **找冲突**：几片镜片解释不一致时，**不一致的地方就是最该去查的地方** | 3 分钟 |

**第 3 步是全部落点。** 格栅的产出不是"结论"，是"**这里有个矛盾，去查**"。

## 五、对芒格用法的三处修正

原版格栅有已知的失败模式，不处理会害人。

| 原版问题 | 修正 |
|---|---|
| **模型通胀**：模型越多，越容易"什么现象都能解释"，最后变成事后合理化 | 卡在 **60–80 条**，每条必须有边界。到顶后只换不加 |
| **事后解释强、事前预测弱**：模型几乎都能解释已发生的事，很少能预测 | 格栅只用于**生成待查清单**，不用于下结论。结论必须回到证据（H1 / G14） |
| 最重要的一条 | **格栅给的是"另一种可能"，不是"正确答案"。** 它最大的用处是防止你只想到一种解释 |

## 六、什么时候格栅没用（必须知道）

| 场景 | 为什么 |
|---|---|
| 有明确技术答案的问题 | 直接查规范、跑实验。上格栅是浪费时间，还会用"视角"掩盖无知 |
| 需要领域细节的判断 | 格栅给不了细节。**深度永远优先**——格栅是横向提醒，不是纵向替代 |
| 时间压力下的操作决策 | 三分钟内要动手的事，用清单和流程 |
| 你已经很确定的领域 | 老手直觉通常比模型快且准。格栅只在你不确定处有价值 |

**一句话：格栅治"我没想到还有这种可能"，不治"我不知道细节"。**

## 七、怎么长（维护规则）

| 规则 | 说明 |
|---|---|
| **按需取，不许从第一章读起** | 按"当前要判的那件事"定向取，取完就停 |
| **单次投入 ≤1 小时** | 超了说明在读教材，不是在补判据（G04） |
| **被调用过三次才留住** | 三个月没被任何一次真实判断调用过的卡片，删掉或合并（H10） |
| **只在"被坑过"之后新增** | 现有卡片都解释不了、且这个现象后来真造成后果 → 才为它加一条 |
| **冲突优先记录** | 两条卡片对同一现象给出相反解释时，把冲突写进双方的「边界」，不要选一个信（同总纲 6.2） |
| **不加"某本书的观点"** | 只收能被反复观察到、且能说出边界的机制 |
