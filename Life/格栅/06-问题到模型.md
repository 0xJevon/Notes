# 问题 → 模型（反查入口）

> **这张表是格栅真正的入口。** 卡片是库存，这张表是使用说明。
> 用法：先找"我面对的是什么"，拿**最少三片、尽量跨格**的镜片，然后看它们**在哪里打架**（[[00-格栅总览]] 第四节）。
>
> **格二（逻辑学）是例外**：它的六条管的是"这个推法本身有没有效"，不针对具体内容，所以**几乎每个场景都该额外上一片**。上表里为了不重复，只在少数场景中列出。

---

## 一、十个高频场景

### 1 · 面对一个陌生领域，不知道从哪下手

**信号**：全是新名词，看不出哪些重要。

| 上哪片 | 它会告诉你 |
|---|---|
| M13 选择压力 | 这个领域里谁被筛选、按什么标准。**找出评价标准，等于找到了地图** |
| M14 生态位 | 现在谁占着什么位置，还有没有空位 |
| L02 演绎/归纳/溯因 | 别急着建体系。先看**别人已经推到了哪一步**、哪些结论是溯因来的（看起来很确定，其实只是候选解释） |
| M06 组合爆炸 | 别试图"全面了解"，先把维度数压到 3 个以内 |

**冲突点**：M13 说"跟着现有标准走"，M14 说"别去人多的地方"。→ 先判断你是要**进入**（跟标准）还是**胜出**（找空位）。

---

### 2 · 判断一个趋势 / 一个说法会不会持续

**信号**："以后都是 X 了""这个会一直涨""行业趋势是……"

| 上哪片 | 它会告诉你 |
|---|---|
| M01 复利 | 增长率能持续多久？上限在哪？ |
| M07 临界点 | 现在离阈值多远？过了会不会突变 |
| M15 红皇后 | 这是绝对提升，还是所有人都在跑、相对位置没变 |

**冲突点**：M01 说"还会继续涨"，M07 说"可能已经快到顶"。→ **去找那个上限的具体数字**，找不到就是在信仰。

---

### 3 · 判断一个数字 / 一个结论可不可信

**信号**：有人用百分比说服你；一份统计看起来很整齐；"检测准确率 99%"。

| 上哪片 | 它会告诉你 |
|---|---|
| M02 基准率 | 先验是多少？证据只是调整比例 |
| M04 幂律 | 平均值有没有代表性？看最大值/中位数比值 |
| M05 回归均值 | 这是极端值之后的自然回落吗 |
| M16 冗余（样本版） | 这份统计的样本，是不是同一个来源的重复 |

**冲突点**：这几片通常不冲突，而是**叠加扣分**。任何一片不过关，这个数字就不能直接用。

---

### 4 · 判断一个系统为什么出问题

**信号**：明明各环节都在努力，整体还是不行；改了没用；越治越糟。

| 上哪片 | 它会告诉你 |
|---|---|
| M11 瓶颈 | 产出卡在哪一环（判据：加资源也不会变快的那环） |
| M07 临界点 | 是不是已经过了某个阈值，性质变了 |
| M09 反馈环 | 是不是有正反馈在放大，或有负反馈在拉回 |
| M10 延迟 | 是不是改得太频繁，叠加成了过冲 |
| M08 熵 | 维持秩序的成本没人付，在缓慢退化 |

**冲突点**：M11 说"补瓶颈"，M08 说"整体维持成本不够"，M09 说"别补，会让回路更强"。→ 先判断是**单点问题**还是**结构问题**。

---

### 5 · 判断一个人 / 一个组织为什么不配合

**信号**："他们就是不重视""说了很多次还是这样""制度写得很清楚"。

| 上哪片 | 它会告诉你 |
|---|---|
| M17 激励 | 照做对他有什么坏处？通常是一个很小但很痛的成本 |
| M19 损失厌恶 | 他是不是把现状当成已拥有的东西，在防着失去 |
| M23 委托代理 | 他掌握你不知道的信息，且在某个环节可以省力不被发现 |
| M20 社会认同 | 这是他的判断，还是他在看别人怎么做 |

**冲突点**：M17 说"改规则"，M20 说"改别人的行为（示范）"。→ 如果这个行为**不能被验证对错**，M20 更有效；如果**有明确后果**，M17 更有效。

---

### 6 · 判断该不该继续投入（项目 / 岗位 / 关系）

**信号**："已经投入这么多了""再坚持一下""沉没成本不要管，但……"

| 上哪片 | 它会告诉你 |
|---|---|
| M22 边际 | 下一个单位的成本和收益，与总量无关 |
| M21 机会成本 | 放弃的那件事有多好（要具体） |
| M03 期望值 | 这个决策能重复吗？不能重复就别算期望 |
| M12 安全边际 | 最坏情况能不能活下来 |

**冲突点**：M22 说"边际还正，继续"，M21 说"机会成本已经太高"。→ 边际算的是**这一件事**，机会成本算的是**你的人生**。两者冲突时，看这件事占了你多少不可替代资源。

---

### 7 · 判断该不该扩张 / 该不该合作

**信号**："上规模就能降本""合并之后更强""我什么都比他们强，为什么还要合作"。

| 上哪片 | 它会告诉你 |
|---|---|
| M26 规模经济 | 现在在曲线哪一段？协调成本涨得多快 |
| M25 比较优势 | 比相对优势，不比绝对水平 |
| M23 委托代理 | 合作方掌握什么你不知道的信息 |
| M16 冗余 | 合作会不会引入新的单点 |

**冲突点**：M26 说"再大一点更省"，M11 说"瓶颈不在规模"。→ 先确认**省的是哪种成本**。

---

### 8 · 判断某个风险有多大 / 该不该防

**信号**："万一出事怎么办""这个概率很低，不用管""必须做最坏打算"。

| 上哪片 | 它会告诉你 |
|---|---|
| M04 幂律 | 尾部有多重？损失会不会是毁灭性的 |
| M03 期望值 | 概率可估吗？不可估时它在骗人 |
| M07 临界点 | 越过之后可不可逆（不可逆的要单独加权重） |
| M12 安全边际 | 你能承受几次这样的损失 |

**冲突点**：M04 说"必须防尾部"，M03 说"期望值很低，不值得"。→ **判据是"可逆性"**：不可逆的损失，不能用期望值决策。

---

### 9 · 判断自己是不是想错了

**信号**：分析非常顺、证据非常充分、对方怎么就是不明白。

| 上哪片 | 它会告诉你 |
|---|---|
| L01 必要/充分 | 我这句结论是被证据**保证**的，还是只够说"不能排除" |
| L02 三种推法 | 我这个"所以"是演绎、归纳还是溯因？后两种不能写成"必然" |
| L03 反例 | 什么观察会让这个结论作废？我找过吗 |
| M18 确认偏误 | 什么证据能改变我的结论？我找过反例吗 |
| M02 基准率 | 我的先验是不是太自信了 |
| M05 回归均值 | 我把自然回落当成自己的能力了吗 |
| M10 延迟 | 我是不是在没到点的时候就下结论了 |

**冲突点**：这一组不产生冲突，它产生**一个具体动作**：去找一条反例。找不到才继续。

---

### 10 · 判断一个"共识"靠不靠得住

**信号**："业内都这么做""大家都这么认为""没有人反对"。

| 上哪片 | 它会告诉你 |
|---|---|
| M20 社会认同 | 这是判断还是互相参照？第一个这么做的人什么理由 |
| M15 红皇后 | 共识的形成是因为标准提高了，还是因为竞争 |
| M08 熵 | 这个共识是不是只是"没人维护、所以留下来了" |
| M13 选择压力 | 它服务于谁的利益 |

**冲突点**：M13 说"它被环境选择下来了，一定有道理"，M20 说"可能是互相参照的产物"。→ 追问一句：**去掉所有人都在做这个前提，它还对吗？**

## 二、走一遍（完整示例）

> **场景（假设）**：一次评估报出 300 条高危，甲方问"要不要全修"。
> 这不是真事，只是示范怎么用格栅——**真实判断必须回到证据**。

**第一步 · 认出信号**：这是「该不该继续投入」+「数字可不可信」的混合。

**第二步 · 上三片，尽量跨格**

| 镜片 | 它会说什么 |
|---|---|
| M02 基准率（数理格） | 300 条是在什么基数上算的？假阳性率多少？先算**绝对假阳性条数**，不是比率 |
| M22 边际（制度格） | 修第 300 条的成本和收益，与修第 1 条完全不同。要的是**排序**，不是"全修"这个二元选择 |
| M17 激励（心智格） | 谁负责修？修完对他有什么好处？如果答案是"没有，还耽误业务"，那这 300 条一条都不会被修 |

**第三步 · 找冲突（关键）**

- 数理格说：**排出优先级，按比例修前 N 条**
- 制度格说：**边际收益递减，修到某个点就该停**
- 心智格说：**前两条都建立在"有人会去修"上，而这个前提不成立**

→ **冲突点不是"修多少条"，是"有没有人愿意修"。**

**结论的正确形状**：不是给一个数字，是给一句待查——
> "先确认修复责任落在谁身上、他修完得到什么。这个不解决，排优先级没有意义。"

**这才是格栅的产出：一个更准的问题，不是一个更漂亮的答案。**

## 三、练法（三条）

| # | 练什么 | 怎么算练过 |
|---|---|---|
| 1 | **每次只上三片，且必须跨格** | 三片都来自同一格 → 不算练习，那是加深偏见 |
| 2 | **强制写"冲突点"** | 写不出冲突，说明三片说的是同一件事，换一片角度不同的 |
| 3 | **记下哪片没用** | 每季度看一次：三个月没被调用过的卡片，删掉或合并（[[00-格栅总览]] 第七节） |
