# 脊柱清单

> **为什么是清单，不是教材**：知识结构不是一片面积，是**几十根跨域主干 + 极长的尾巴**。主干能跨十几个领域迁移，尾巴只在一个领域成立、换域即失效。
> 复利不来自覆盖面，来自**复用率**——一个概念被用过 30 次才生息；知道 300 个只用一次的概念，产生的是折旧。
> 所以这张表只收主干，而且**只写"什么时候该想起它"，不写它是什么**。它是什么，AI 一秒能给你，没有存的价值。

## 四、怎么用（三条，别加）

| # | 规则 |
|---|---|
| 1 | **下结论前扫一遍第二列。** 被问住的那一条，就是当前最大的缺口——那一条就是你今天该补的东西，而不是清单上排第一的那条 |
| 2 | **"最近一次调用"写日期 + 半句话场景**（如 `2026-11-02 定级时用它压掉了'可能被组合'`）。写不出场景的，是假装填过 |
| 3 | **同一条被连续救了两次 → 考虑上升为通用条目**（走 [[000-知识库总纲]] 第六章四判据，记进 [[09-沉淀日志]]）。这是这条线唯一往 `_通用/` 供货的通道 |

## 五、刻意没收进来的东西

| 类别                | 为什么                        |
| ----------------- | -------------------------- |
| 物理、化学、生物的具体定律     | 那是叶片。需要时查，查得到的不必存（G16）     |
| 统计学的公式与推导         | 同上。缺公式的时候，你会知道自己缺          |
| 逻辑学的名词体系（三段论、真值表） | 库里已有的判别模型已经在做形式化，回头学名词没有增量 |

**这张表如果要加，只加"能在三个不同领域各用一次"的概念。** 用不到三个领域的，不进这张表。
