# 知识库运转规则

> 来源：红队库的三层结构设计，2026-10-27 抽象为通用规则。
> 这一篇管的是**库本身的机械结构**，不是内容。结构错了，内容再好也会烂掉。

---

## G14 三层：证据 / 问题 / 项目

**一句话**：任何领域的知识库都必须把「**事实**」「**疑问**」「**做过的事**」分开存，混在一起必然退化成流水账。

| 层 | 收什么 | 不收什么 |
|---|---|---|
| **证据层** | 当时真实的原始输出、原始记录，原样粘贴 | 事后整理的"应该是这样"、AI 生成的解释 |
| **问题层** | 卡住的地方 → 可执行的实验设计 + 关闭条件 | 没有关闭条件的疑问、纯概念好奇 |
| **项目层** | 做过的事：项目、演练、报告、工具 | 只做了没复盘的项目 |

**核心规则：证据层是唯一有资格被引用的事实来源。** 正文里任何"我记得是这样"的论断，都要能指到证据层的某条记录；指不到的，一律写成「待验证」。

**动作**：写任何结论前，先问"这一条能指到哪份原始记录"。指不到，降级为假设。

**失效条件**：**纯理论领域**（数学、哲学）没有"证据层"这个东西，那里的证据是推导过程。此时三层压缩为两层：推导 + 问题。

**已验证**：红队（2026-10-27）。

## G15 问题必须有关闭条件，否则就是待办墓地

**一句话**：一个问题的价值，取决于**你能不能说出它什么情况下算解决**。说不出的，不是问题，是焦虑。

**动作**：每条问题必须写四样：现象 / 我的猜测 / 实验设计 / **关闭条件**。四样缺一样，不许建。

**关闭条件的三层**（缺一不算关闭）：

1. 能不看资料复现 —— **操作层**
2. 五格填得满（G07） —— **认知层**
3. 能说出失效条件 —— **边界层**

**只满足第 1 条的，不算学会，只能算会抄。**

**防墓地机制**：`待验证` 超过 **15 条**，立刻停掉所有新输入，先清队列。囤问题不做事，是这类知识库最常见的死法——它给人一种"我在进步"的错觉，实际上是负债在累积。

**失效条件**：探索期（刚进一个新领域，1-2 周内）允许问题堆积，因为此时还分不清哪个重要。超过两周就必须开始关。

**已验证**：红队（2026-10-27）。

## G16 禁止入库清单

看到就跳过，不许写进来：

| 禁入内容 | 理由 |
|---|---|
| **AI 生成的解释**（未验证） | 要用就先做成实验，跑通后用自己的话写 |
| **抄来的步骤**（没自己跑通） | 那不是知识库，是别人的博客备份 |
| **参数/选项清单** | 有 `--help` / 有搜索，就不需要笔记 |
| **刷题答案** | 别人的总结，不是你的证据 |
| **原理复述**（"X 就是把 A 拼进 B"） | 知道这个不算能力 |
| **只有结论没有前提的"经验"**（"优先用 X"） | 必须写成"在什么条件下优先用 X" |

**一句话判断**：这条内容能不能让我**下次遇到类似场景时少走弯路**？答不出就删。

**失效条件**：**索引类内容**（别人的目录、检查表、清单）可以入库，但只能作为"覆盖面检查表"，不能当作知识本身。

**已验证**：红队（2026-10-27）。

## G17 一次单元三件产出，缺一不算完成

**一句话**：任何一次"做"（打靶、项目、演练、真实任务），必须留下三样东西，否则等于没做。

```
1. 证据：原始记录（命令/输入 + 真实输出/结果），不改写、不美化、不补全"应该是"
2. 问题：卡住的点 → 现象 + 猜测 + 实验设计 + 关闭条件
3. 结论：一句话机制结论，写进对应的正文
```

**为什么必须三件**：只留 1 是操作日志（下次还得重新想）；只留 2 是焦虑清单（越积越多）；只留 3 是无根结论（经不起追问）。**三件合起来才构成"可复用的经验"。**

**变体**：不能"做"的时候（只有阅读条件），产出形态换成**假设**——落进问题层，标 `待验证`，等有环境时验证。阅读不是补料，是没条件做的时候唯一能产生假设的方式。

**失效条件**：无。（这是最低标准，不是最高标准）

**已验证**：红队（2026-10-27）。

## G22 环要有台账：没有轮次记录，环会退化成重复

**一句话**：多轮练习的价值全在"这一轮和上一轮哪里不同"，而这个差异**记不住**——必须写下来，否则第 4 轮和第 1 轮长得一模一样。

**为什么放在运转规则里**：环怎么设计在 G19（学习节奏），环是不是真的在转，看这张表（库的机械结构）。**没有台账的环，只能证明你重复了，不能证明你进步了。**

**动作**：任何多轮练习开一张表，一行一轮，四列：

| 轮次 | 焦点（只一个） | 变了什么约束 | 上轮错收了没 |
|---|---|---|---|
| 1 | | — | — |
| 2 | | 时间 / 清单 / 打法 / 限制，至少变一项 | 收 / 未收 |
| 3 | | … | … |

**三条硬规则**：

1. **约束没变，不算新的一轮**——那只是把上一轮又做了一遍
2. **上一轮的错没收掉，不许开下一轮**（3 分钟口述错因，说不出就回炉）
3. **连续 3 轮失败原因相同 → 停**，换环境或换焦点，别再刷

**这张表只写一行字，不是日志。** 写不出"这轮变了什么"，说明这一轮不该开。

**失效条件**：一次性机会（真实项目、应急、演练）没有"轮次"，改为「一次做透 + 事后拆成可重复的小环」。清单型知识（查表就够的）没有环，不要给它硬套。

**已验证**：红队（2026-11-03）。来源：网络线问题库 8 条活着、只关 1 条，其中 3 条已第 2–3 次出现且全被"挂到后面的单元"放行——有环的形式，无环的收敛。
