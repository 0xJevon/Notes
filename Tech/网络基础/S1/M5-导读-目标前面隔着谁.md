# M5 目标前面隔着谁

> 归属：[[00-学习地图]] ｜ 答题：[[M5-问答]] ｜ 上一单元：[[M4-导读-包怎么被转发]]

## 1. 这个单元要回答什么

一个问题：**你打的那个 IP:端口，是真身，还是外壳？**

上次你答对了「外网连不进内网是 NAT 的副作用」。这一单元把"连得上但连到的不是真身"这件事拆开——三种设备，三层完全不同的动手位置。

| 设备 | 在哪一层动手 | 按什么做决定 | 你看得见什么 |
|---|---|---|---|
| **包过滤防火墙** | 网络层／传输层 | 源/目的 IP、端口、协议、状态 | 端口 open 或 filtered，没有别的痕迹 |
| **反向代理 / WAF** | 应用层（**终结 TCP**） | Host、路径、请求内容 | 响应头多一层，响应体可能是拦截页 |
| **CDN** | **DNS 层**（改解析结果） | 调度策略（就近、负载） | 解析出的 IP 不是源站，多地结果不同 |

**关键区别：防火墙和反代是"流量到了才判断"，CDN 是"你的流量根本没往源站去"。** 前者是拦截，后者是改道。

## 2. 核心机制

### 2.1 防火墙只看信封，不看信

包过滤防火墙不解包内容，它只比对五元组和状态表：源 IP、目的 IP、源端口、目的端口、协议，加上"这条连接是不是我先放出去的回程"。

所以它做得成的事：**放行/拒绝某个端口、某个来源、某个方向**。
它做不成的事：**认出 HTTP 请求里带了 SQL 注入**——那要看内容，得由 WAF 或反代来干。

一个常见现象由此而来：**端口 open 不等于服务在**。防火墙放行了 443，但后面没服务，你会得到"连上就断"；反过来服务在、防火墙 drop，你会得到"一直等到超时"。两者超时时间完全不同——这就是 N09 那条的实战版。

### 2.2 反向代理：TCP 到它为止

```text
浏览器 ──TCP──> 反向代理 ──另一条TCP──> 源站
         (到这里就终结了)      (这条是反代发起的)
```

这是最容易被忽略的一点：**你跟反代建连接，源站跟你之间没有连接。** 源站看到的所有 TCP 连接都是反代发起的。

后果有三条：

- 源站看到的**源 IP 是反代的 IP**，不是你。要拿真实 IP 只能靠 `X-Forwarded-For` 这类头——而**这个头是代理自己加的，客户端也能伪造**，所以源站通常只信第一层可信代理写的那一段。
- 一台机器上多个站点，靠 **Host 头**区分由反代来做（K02 的边界被搬到了另一台设备上）。
- 换了 Host 还是同一个页面，说明这一层**不按域名分流**；换 Host 回不同站，说明前面站着按域名分流的设备。

### 2.3 CDN：改的是解析，不是流量

CDN 不拦你的包，它让**你的包本来就发到边缘节点去**。做法是把域名的解析结果指向就近的边缘节点。

所以识别 CDN 不看流量，看解析：

```bash
dig +short www.example.com        # 多个 IP、且属于 CDN 厂商的段
dig @8.8.8.8 www.example.com      # 换 DNS 再问，结果不同 = 按来源调度
```

**判断口诀：解析出来一堆分散的 IP、多地结果不一样，先怀疑 CDN；只有一个 IP、归属是 IDC，才可能是源站。**

## 4. 为什么这样设计

**为什么不干脆让防火墙看内容？** 因为它站在网络层，看内容要重组成完整请求，代价是性能和协议耦合；而且加密流量（HTTPS）它根本看不到。要看内容就得**终结加密**，那是应用层设备（反代/WAF）的活。

**反代的代价**：源站再也拿不到真实客户端 IP，多了一跳延迟，且反代本身成为单点和新的攻击面（它就是那个"能看见明文"的位置）。

**CDN 的代价**：源站控制权被削弱——缓存什么时候更新不由你说了算，动态内容要回源，出错时你先怀疑自己再怀疑 CDN。

## 5. 动手验证（2 分钟）

```bash
# 1. 看解析出几个 IP、是不是 CDN 段
dig +short www.taobao.com

# 2. 看响应头有没有中间层的痕迹（Server / Via / X-Cache / CF- 系列）
curl -sI https://www.taobao.com | head -15

# 3. 换 Host 打同一个 IP，看回的是不是同一个站
curl -sI https://<上一步的IP>/ -H 'Host: www.taobao.com' | head -5
```

第 3 步是这一单元最有用的动作：**同一 IP、换 Host，回什么。** 回同一个站 → 前面没有按域名分流；回不同站或报错 → 有；回证书错误 → 说明它在等一个特定域名（SNI）。
