# 网络基础 · 学习地图

## 这个库是什么

不是一个"网络知识库"，是一个**训练场**。

原因：网络的概念本身，AI 一秒就能给你一份解释。你缺的不是解释，是**能不能在不看答案的情况下预测一条链路的行为**。所以这里的材料只做三件事：给地图、指出坑、出题。真正的价值在你写的答案里。

## 目标

对计算机网络的核心机制形成稳定理解——每条结论都能回答三个问题：

1. 它解决什么问题？（没有它会怎样）
2. 它的代价是什么？（为什么不可能完美）
3. 为什么不用更简单的做法？（谁被牺牲了）

答不出这三条，就说明还停在术语层。

## 三条铁律

1. **先自己答，再看材料或我的反馈。** 顺序反了，训练量为零，只剩"读懂感"。
2. **问题的答案不在书里。** 书上有的，我不问。
3. **每个单元有一次动手验证。** 网络是唯一能每天看到证据的领域，不用它做校验太浪费。

## 职业校准：五个判定场景

这条线不是为了"懂网络"，是为了在下面五件事上不再卡住。**每学完一个单元，回来在这张表里划一格**——表填不满，说明方向偏了。

| 场景 | 现场长什么样 | 判不出来的后果 | 补它的单元 |
|---|---|---|---|
| **判解析失败 vs 连接失败** | `Could not resolve host` / `Connection refused` / `Operation timed out`，三种混着看 | 定位到错的层，白查两天 | M2、M3 |
| **判 NAT 前后是谁** | 会话表里内网 10.109.x.x 与出口地址成对出现，端口被改写 | 攻击源定错，封禁封到别人头上 | M8、M9 |
| **判防火墙规则方向** | 日志里 src/dst 与直觉相反；规则写的是"允许从 A 到 B" | 放行写成阻断，排障时把责任推给运营商 | M11 |
| **判 CDN / 反向代理** | 解析出的 IP 不是源站；响应头多一层 `Via`/`X-Cache`；证书域名与业务域名不一致 | 把 CDN 节点当源站报漏洞，交付被退回 | M12、M13 |
| **判连接状态** | `CLOSE_WAIT`、`SYN_RECV`、`TIME_WAIT` 在同一张会话表里堆着 | 把应用 bug 当网络故障，或把扫描当攻击 | M3、M4 |

对照诊断结果：Q2（把解析失败定性为应用层故障）落在第 1 条，Q8（把 `SYN_RECV` 理解反）落在第 5 条，两条都判错了。

**这张表决定顺序，不决定内容。** 内容仍是书里那套机制，只是把最常撞的排前面。

## 与重构后总纲的接口

这条线是 `Tech/00-技术底座地图` 里**唯一被允许独立推进**的子线。独立推进的理由和边界必须写在明处，否则三个月后会被自己的规则判成违规。

| 总纲条款 | 这条线怎么执行 |
|---|---|
| **G03 先直面问题**（本线是例外） | 例外理由：安全服务的日常判断（防火墙日志方向、DNS 失败、NAT、代理与 CDN 识别）需要一张**先验地图**，缺图时连"卡在哪"都说不出来。**边界**：每个单元的题必须能落到一个具体现象上；连续两个单元找不到落地现象 → 停线，回 Security 主线 |
| **H3 / G16 AI 生成内容不入库** | `导读` 定性为**脚手架**（G16 失效条件允许"覆盖面检查表"入库），只负责指坑和出题；我写的 `反馈` 也只是过程记录。**唯一入库物是每单元"沉淀"里你自己写的那一句** |
| **G15 问题必须有四要素** | 卡点一律进 [[_问题库]]，现象/猜测/实验设计/关闭条件齐全才建；关掉的搬去"已关闭"并写靠什么关的 |
| **G17 一次三件产出** | 本线的"一次" = 一个单元：**证据**（你的原始作答，含错的）+ **问题**（进问题库）+ **沉淀**（自己那句话） |
| **G04 2 小时规则** | 单单元（读 + 答 + 沉淀）控制在 **90 分钟内**。超时不是你不努力，是材料粒度错了——告诉我拆单元 |
| **G09 负知识保留** | 答错的原文不删不改，反馈并列写在后面，不覆盖 |

## 怎么用

**完整操作手册 → [[02-怎么用]]。** 这里只留六行：

1. 每个单元：读导读 → 读原书指定页 → 动手验证 → **合书答题** → 写沉淀 → 交回
2. 我按三段反馈（对在哪 / 错在哪 + 缺的那一环 / 再深一层的追问），不打分
3. 答错的题不回滚，原处留着（G09 负知识必须保留）
4. **拿到反馈后 24 小时内回炉 10 分钟**：重写沉淀（如结论被改）+ 改问题库状态 + 改 `status`。**不做完这一步，不开下一个单元**
5. **沉淀五格**（机制 / 矛盾 / 代价 / 失效条件 / **现场信号**）过一句验收，我回三档（过 / 差一层 / 打回）；**过了才复制进 [[_结论]]**——那是这条线唯一进正文的地方
6. 每 3 个单元做一次 10 分钟回访（见 [[_问题库]] 回访计划），阶段末尾交闸三产物

**判完就往下走 = 把反馈当读物。** 48 小时后忘掉八成，然后带着同一个洞进下一单元。

诊断已完成（2026-10-27），逐题反馈见 [[01-诊断]]，据此新增 M0 作为起点。
