## 验证区（先跑，输出贴这里，不许改写）

### A｜同一个账号，两枚令牌（各 2 分钟）

先在**普通** PowerShell 里跑（双击打开，标题栏没有"管理员"字样）：

```powershell
whoami /user
whoami /groups | Select-String 'Mandatory Label|BUILTIN\\Administrators'
whoami /priv | Select-String 'SeDebugPrivilege|SeImpersonatePrivilege|SeTakeOwnershipPrivilege|SeBackupPrivilege'
```

再在**终端(管理员)**里跑同样四条（Win + X → 终端(管理员)）。

两段输出贴这里，标清哪段是普通、哪段是管理员：

```text
（普通 PowerShell）

（管理员终端）
```

### B｜快照实验（10 分钟，这段是本单元的核心证据）

管理员终端加组：

```powershell
$me = $env:USERNAME
net localgroup "Remote Desktop Users" $me /add
```

**立刻回到那个没关过的普通 PowerShell 窗口**（不要关、不要重开、不要切用户）跑：

```powershell
whoami /groups | Select-String 'Remote Desktop'
```

然后**注销并重新登录**（会关掉所有窗口），重新开一个普通 PowerShell，再跑一次同一句。

清场（管理员终端）：

```powershell
net localgroup "Remote Desktop Users" $me /delete
```

两次输出贴这里：

```text
（加组后、未重新登录）

（注销重登后）
```

### C｜一次网络登录（可选，5 分钟，做不了直接跳过）

```cmd
net use \\127.0.0.1\IPC$ /user:%COMPUTERNAME%\%USERNAME%
```

输完密码后：事件查看器 → Windows 日志 → 安全 → 筛选当前日志 → 事件 ID `4624` → 看最新那条的「登录类型」。

同时跑一句 `query user` 对照。

```text
（4624 的登录类型 / query user 输出）
```

> 这一步失败不影响答题。IPC$ 或管理共享被关掉时必然会失败，跳过即可。
