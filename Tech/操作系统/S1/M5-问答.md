## 沉淀

> 本单元的机制是 **2.1 句柄 + 2.3 Linux 三层（fd / file description / inode）**：打开对象时检查一次权限并返回一个引用，之后所有操作都用这个引用，不再回查。
> 判断落点：**判"有权限却用不了"与"权限已收回却还能用"分别是什么造成的。**

| 空 | 填什么 |
|---|---|
| ① 机制 | 打开时 ______ 检查一次，返回 ______，之后 ______ 据此决定 ______ |
| ② 它解决的矛盾 | 每次操作都查权限会怎样 |
| ③ 代价 | 一次性检查带来什么后果 |
| ④ 失效条件 | 什么情况下这个引用不代表当前权限 |
| ⑤ 现场信号 | 在 ______（句柄列表 / /proc/pid/fd / df）上表现为 ______；判错会看到 ______ |
