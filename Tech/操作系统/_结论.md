# 操作系统 · 结论台账

> **这条线唯一进正文的地方。** 导读、问答、反馈都是过程记录，按 H3 不入库。
> 一行 = 一个单元。**只有过了验收的那句才能进这里。**

## 规则

1. 每单元最多一行。写不出就留空——空着比写一句错的强。
2. 一句话必须把五格填实：机制 / 矛盾 / 代价 / 失效条件 / 现场信号。缺任一不收。
3. 没有失效条件的结论是教条（总纲硬规则 4）。
4. 验收未过的留在问答文件里，不进此处。
5. **双平台单元（M0–M8）的结论要写"两边各怎么做"**，只写一边算"差一层"。
