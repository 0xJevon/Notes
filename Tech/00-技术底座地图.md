> **定位：补给线，不是主攻方向。**
> 它只为"主线卡住时回补"服务。它不该抢主线的任何一分钟——抢了，就是用"学基础"逃避"动手做"（违反 G03）。

## 一、边界规则（先看这个）

| 规则 | 说明 |
|---|---|
| **不主动推进** | 没有具体卡点，不打开这条线 |
| **只补卡住的那一点** | 不是"系统学一遍网络"，是"隧道走不通，去查 M11 那一节" |

**例外**：`网络基础` 这条线正在跑，它是唯一有训练形态的技术线，允许独立推进（见第二节）。

## 二、网络基础（唯一在跑的子线）

`网络基础/` 是全库**训练形态最好的一条线**，红队线的方法论有好几条是从它的设计里反推出来的：

- 定位是"**训练场**"不是知识库——"网络的概念 AI 一秒给你解释，你缺的是不看答案能不能预测一条链路的行为"
- 结构是 **导读 + 问答**成对出现，**先自己答再看反馈**
- 目标是每条结论能答三问：解决什么问题 / 代价是什么 / 为什么不用更简单的

**进度**：S1 的 M0–M3 已出材料（地址掩码与网关 / URL 到 HTTP / 域名到 IP / 套接字与连接），M4 起未出。

**状态**：`进行中`，但**优先级低于 Security**。它吸收的是碎片时间，不是主攻时段。
