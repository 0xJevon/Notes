# Tech · 技术底座线

> **定位：补给线，不是主攻方向。**
> 它只为"主线卡住时回补"服务。它不该抢主线的任何一分钟——抢了，就是用"学基础"逃避"动手做"（违反 G03）。

## 一、边界规则（先看这个）

| 规则 | 说明 |
|---|---|
| **不主动推进** | 没有具体卡点，不打开这条线 |
| **只补卡住的那一点** | 不是"系统学一遍网络"，是"隧道走不通，去查 M11 那一节" |
| **一次回补不超过 2 小时** | 超了说明补错了方向，回到 G04 |
| **不许因为"应该懂"而学** | "应该懂"是最容易变成收藏夹的理由 |

**例外**：`网络基础` 这条线正在跑，它是唯一有训练形态的技术线，允许独立推进（见第二节）

**最终只补建一套：`操作系统/`**（9 单元，Linux 与 Windows 对照：主体标识 → 认证凭证 → 特权能力 → 提权切换 → 访问控制 → 对象句柄 → 服务守护进程 → 隔离保护 → 日志审计）。理由和另外四块不同：

| | 为什么要/不要训练场 |
|---|---|
| **操作系统/权限** | 是**判据链**：缺一环，后面全是猜；且答案不在书里，只能在"我以为能、实际被拒"的摩擦里长出来。必须有答题、有沉淀、有台账 |
| 数据库 / 密码学 / Web 架构 / 代码阅读 | 是**条目**，不是链。写进 [[../Career/03-必学清单]] 当清单，卡住再查，不需要答题形态 |

`Tech/` 下其余散稿（关系型数据库、开发语言）保持"查得到就行"，不升级成线。

## 二、网络基础（在跑的子线之一）

`网络基础/` 是全库**训练形态最好的一条线**，红队线的方法论有好几条是从它的设计里反推出来的：

- 定位是"**训练场**"不是知识库——"网络的概念 AI 一秒给你解释，你缺的是不看答案能不能预测一条链路的行为"
- 结构是 **导读 + 问答**成对出现，**先自己答再看反馈**
- 目标是每条结论能答三问：解决什么问题 / 代价是什么 / 为什么不用更简单的

**进度**：S1 的 M0–M4 已出材料（地址掩码与网关 / URL 到 HTTP / 域名到 IP / 套接字与连接 / 包怎么被转发），K06（防火墙·代理·CDN 识别）与 K07（TLS 与证书）待写。全表 7 节点、约 6 小时。

**状态**：`进行中`，但**优先级低于 Security**。它吸收的是碎片时间，不是主攻时段。

## 三、操作系统（在跑的子线之二）

**9 个单元，Linux 与 Windows 对照**：主体标识 → 认证凭证 → 特权能力 → 提权切换 → 访问控制 → 对象句柄 → 服务守护进程 → 隔离保护 → 日志审计。

只讲"权限如何生效、行为如何留痕"，不讲操作系统教材那套（调度、内存、文件系统实现一概不学）。**入口：[[操作系统/00-学习地图]]**；起点：[[操作系统/01-诊断]]。

它与网络基础的分工：网络回答"包怎么走"，这里回答"谁能做什么、做了留什么"。两者都不替代 Security 主线。

## 五、覆盖边界：这两条线管到哪，不管什么（2026-11-03 增补）

问"网络和 OS 够不够用"，先看它服务哪条验收。**这两条线只覆盖 V1 和 V4，不覆盖 V2、V3。**

| 验收 | 覆盖情况 | 依据 |
|---|---|---|
| **V1** 8h 拿到第一台主机 | **够** | 网络 K01–K05 判"通不通、打到的是谁"；OS M0–M5 判"能不能提、为什么被拒" |
| **V4** 画图逐段解释 | **够** | 七节点 + 九单元合起来就是那条链的语言 |
| **V2** 24h 推到域管 | **不够，且不是这两条线能补的** | 缺 AD（目录服务与授权模型）、内网协议栈（SMB/RPC/LDAP/WinRM） |
| **V3** 不触发有效告警 | **不够** | OS M8 只到"留了什么痕迹"，没到"检测器在哪一层、怎么绕" |

**五样明确不在这两条线里，别在这儿找：**

| 缺的东西 | 为什么不属于底座 | 归哪 |
|---|---|---|
| **AD / 域** | 是目录服务与授权模型，不是操作系统的子集；OS M1 只讲令牌、登录类型、Kerberos 名字 | **F 域**（Loop 3 后建） |
| **内网协议栈**（SMB/RPC/LDAP/Kerberos/WinRM 的线上形态） | 网络线七节点全是"公网请求"视角（URL→IP→TCP→包→前置设备），没有内网横向这一段 | **E 域**（Loop 3 就要用） |
| **驻留载体**（计划任务 / WMI / 注册表 Run / COM / 启动项） | OS M6 讲的是"服务以谁跑、能不能劫持"，是提权视角；载体属"活下来" | **C 域** |
| **PKI 与证书链** | 网络 K07 只回答"证书在证明什么"，不回答"怎么给自己签一张能过的" | **G 域**（C2 走 HTTPS 时） |
| 云 / 容器 / 虚拟化 | 各家实现不同，且现在才刚碰到 ZStack | M5，等第二个云项目 |

**一句话：底座线的判据层已经够用。缺的不是学科，是链路上的域。** 继续往底座里加内容，就是在用"学基础"回避"打不穿"（违反 G03）。
