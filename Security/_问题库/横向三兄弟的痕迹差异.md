# 横向三兄弟的痕迹差异

> **P0 · 工具使用者 → 原理掌握者。** 自评 Q5 认为"都要落地 impacket"。
> 实际 impacket 在你的攻击机上，落地的是它上传的文件——三者的差别恰好就在这里。

## 现象

- 我分不清 psexec / wmiexec / winrm 到底差在哪。
- 只知道"都是横向的手法"。

## 我的猜测（先写自己的，再往下做）

> （先猜：如果防守方只能看 Windows 事件日志，哪个最难被发现？为什么？）

## 实验设计

环境：**同一台**目标机，**同一个凭据**，分别用三种手法执行同一条命令（比如 `whoami`），每次之后**立刻**去目标机看日志，逐项记录：

| 记录项 | psexec | wmiexec | winrm |
|---|---|---|---|
| 落地文件（全盘 diff） | | | |
| 服务是否被创建 | | | |
| 7045（服务安装） | | | |
| 4688（进程创建） | | | |
| 4624 的 Logon Type | | | |
| WMI-Activity 日志 | | | |
| 4104（PowerShell 脚本块） | | | |

**日志路径**：
- 安全日志：`eventvwr` → Windows 日志 → 安全
- WMI：应用程序和服务日志 → Microsoft → Windows → WMI-Activity → Operational
- WinRM：同上 → Windows Remote Management
- PowerShell：同上 → PowerShell → Operational

**加分实验**：开 Sysmon（配 SwiftOnSecurity 规则）重跑一遍，看哪种被抓得最狠。
