## 实验设计

环境：Vulnstack 任意域环境，**用普通域用户（非管理员）执行**。

1. 普通域用户跑 `GetUserSPNs.py -request`，记录：
   - 能不能拿到 TGS？需要什么权限？
   - 返回的 etype 是什么（23=RC4 / 17=AES）？为什么 RC4 更容易爆？
   - 目标账号的 SPN 是怎么来的（谁会给账号配 SPN）？
2. 域控上看 **4769**：一次请求留几条日志？有失败记录吗？
3. **对比实验**：对 5 个账号各试 1 个弱密码（一轮喷洒），看 **4625** 有几条。
4. AS-REP 部分：自己建一个勾了「不需要 Kerberos 预认证」的账号，跑 `GetNPUsers.py`，看 **4768**。
