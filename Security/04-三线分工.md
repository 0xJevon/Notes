# 04 · 一条主线、一条支线、一条横切

> **2026-11-18 两次校准**：原"双线（安服代审 + 红队）"作废；"高级攻防安服（砍掉免杀/维持/域纵深）"也作废。
> 定为**攻防兼备的高级渗透测试工程师**：六域全保留到"能独立做完"，AI 编排横切每一段。
> 上位：[[00-能力地图]] · 课程来源：[[05-课程映射与学习顺序]]

---

## 一、三条线的定位

| | **主线：六域** | **支线：代码审计** | **横切：工具链** |
|---|---|---|---|
| 内容 | A 资产 · B Web 入口 · C 组件与边界 · D 提权上线维持 · E 内网与域 · F 交付 | 代审四步：定范围 → 找 sink → 验可达 → 落危害 | MCP / Skill / Agent / Workflow / 模型选型 / 审计与交付的 AI 用法 |
| 验收 | Q1–Q5，见 [[00-能力地图]] | A1–A4，见 [[10-代审支线]] | 每阶段收尾必须交付一个 tool 或 SKILL.md |
| 时间来源 | **学习时间**，20h/周 | **项目时间**，跟着代审任务走 | 不另占时间，从每一段里长出来 |
| 排期 | [[05-课程映射与学习顺序]] S0–S7，29 周 | [[10-代审支线]]，6 周 | 无周次，按 S0–S7 收尾打点 |
| 产物 | 靶场记录 + 证据 + 报告 | 样本卡 + 判定卡 + 报告骨架 | server 源码 + SKILL.md + 调用记录 |

**为什么代审是支线**：它是你已经在做的交付任务，有真实项目喂着，不需要额外挤学习时间。

**为什么工具链是横切不是支线**：它单独立项就没有素材——只有挂在真实任务上，才知道该包哪个 tool、该写哪条红线。单独排"学 AI 的周次"会变成看教程。

## 二、切换规则

1. **主线占学习时间，支线占工作时间**——两者不抢，来源不同。
2. 支线只在"接到代审项目"时激活；没有项目时只维护索引，不排周计划。
3. 支线的每条结论，在样本卡第 6 节写一句"这条链在报告里属于哪一域"——这是两条线唯一的接口。
4. 主线连续两周没进展，必须在 [[001-驾驶舱]] 的四问里写明原因。

## 三、AI 横切的三条硬规则

1. **每段收尾必须有产物。** S0–S7 每段结束前，把该段最耗时的重复动作变成 tool 或 SKILL.md；不做，那段不算完成。
2. **AI 出候选，人出结论。** 它能跑完 200 个子域、读完 3 万行代码，不能替你判"这条值几级""会不会打挂生产"。
3. **红线写进流程层，不写进对话。** 授权范围、顺序、禁止项、落库格式——四样都进 SKILL.md，因为模型每次都可能忘。

五条具体红线（授权、PoC、理论可利用、破坏性命令、红线资产）见 [[03-学习计划]] 第六节。

## 四、共用与不共用

| 共用 | 不共用 |
|---|---|
| `Security/_证据/`：原始输出 | 能力域目录：支线不建 A–F 目录 |
| `Security/_问题库/`：卡点与关闭条件 | 排期：主线按周，支线按项目 |
| `Security/_项目/`：靶场与真实项目 | 产物：样本卡 vs 靶场记录 |
| `_模板/`、`_通用/`：规则与骨架 | — |

## 五、周台账

| 周次 | 焦点（只一个） | 变了什么约束 | 上周的错收了没 | 这段的 AI 产物 |
|---|---|---|---|---|
|  |  | — | — | — |

> 规则：约束没变不算新的一周；上一周的错没收掉，不许开下一周；连续两周失败原因相同 → 停，换焦点。最后一列空着，那段就是没完成。
