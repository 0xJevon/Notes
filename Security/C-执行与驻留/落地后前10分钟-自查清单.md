# 落地后前 10 分钟 · 自查清单

> **这是一份"问题清单"，不是"命令清单"。**
> 命令网上到处都有，AI 一秒给你；这里要的是**每个动作要回答什么问题**——答不出问题的命令敲了等于没敲。
>
> 用法：每次打靶落地后，先不看答案，自己填一遍。填不出来的格子就是这次要学的东西。

---

## 第 1 层 · 我是谁（身份决定路）

| 要回答的问题 | 命令 | 我的答案 |
|---|---|---|
| 我是什么身份？ | `whoami /all` | |
| 我在哪些组？哪个组最值钱？ | 同上，看 `BUILTIN\` | |
| 我有哪些特权？哪些能直接换 SYSTEM？ | 同上，看 `SeXxx` | |
| 我的完整性级别？能不能写高权限进程？ | 同上，看 Mandatory Label | |
| 这个账号是本地的还是域的？ | `echo %userdomain%` | |

> ⚠️ 只看 `whoami` 不看 `/all`，等于没看——丢掉的正是组和特权。

---

## 第 2 层 · 我在哪（位置决定往哪走）

| 要回答的问题 | 命令 | 我的答案 |
|---|---|---|
| 我有几张网卡？**有没有第二张**？ | `ipconfig /all` | |
| 我能不能出网？走什么代理？ | `ping` / `curl` / 看 IE 代理设置 | |
| 我的网段和网关？ | `route print` | |
| 同网段还活着谁？ | `arp -a` | |
| 这台机器连过谁？（**现成的拓扑**） | `netstat -ano` | |
| DNS 服务器是谁？是不是域控？ | `ipconfig /all` | |
| 有没有域？域控在哪？ | `systeminfo \| findstr /i domain`、`nltest /dclist:` | |

> ⚠️ **多网卡 = 你可能站在跳板上。** 这一条决定了整条链往哪走，优先级高于任何扫描。

---

## 第 3 层 · 周围有什么（环境决定风险）

| 要回答的问题 | 命令 | 我的答案 |
|---|---|---|
| 有没有杀软/EDR？哪个厂？ | `tasklist /svc`、`wmic /namespace:\\root\securitycenter2 path antivirusproduct get displayname` | |
| 什么业务在跑？谁在用它？ | `tasklist /svc`、`netstat -ano` 对进程 | |
| 有什么服务？哪个是自建的？ | `sc query type= service state= all` | |
| 有什么共享？ | `net share` | |
| 补丁到什么级别？（决定能不能用 exp） | `systeminfo` 看 Hotfix | |
| 有没有装运维工具（Ansible/堡垒机 agent）？ | `tasklist` | |

---

## 第 4 层 · 有什么现成凭据（**最高 ROI，最容易被跳过**）

| 要回答的问题 | 位置 | 我的答案 |
|---|---|---|
| Web 配置里有连接串吗？ | 站点目录 `web.config`、`appsettings.json`、`.env` | |
| IIS 全局配置？ | `C:\Windows\System32\inetsrv\config\applicationHost.config` | |
| 计划任务里有没有写死密码？ | `schtasks /query /fo LIST /v` | |
| 有没有人敲过明文口令？ | `ConsoleHost_history.txt` | |
| 浏览器存了密码吗？ | Chrome/Edge `Login Data` | |
| 服务里有没有写死密码？ | `sc qc <name>` 看 binPath | |
| 有没有自动登录？ | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon` | |
| 有没有装机遗留文件？ | `C:\unattend.xml`、`sysprep.inf` | |
| 运维留的脚本里有没有密码？ | 共享目录、`C:\Scripts`、桌面 | |
| **这台机器上有域管登录过吗？** | 最后才抓 lsass，看里面有没有域账号 | |

> ⚠️ 这一层的产出通常比抓 lsass 更值钱，而且**不触发任何告警**。先从抽屉里找钥匙，再去撬保险柜。

## 第 5 层 · 怎么活下来

| 要回答的问题 | 我的答案 |
|---|---|
| 我这个权限依赖哪三件事？（文件/服务/权限） | |
| 重启后会怎样？如果是内存马呢？ | |
| 杀软会不会在例行扫描时删掉我？ | |
| 运维会不会通过什么发现我？（日志/文件时间/进程） | |
| 我留下的痕迹有哪些？逐条列出来 | |
