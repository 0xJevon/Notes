# 字典与指纹 · 实战沉淀

> 《红队心法》原话：常规搜集人人都会，**但全部做到位的人真的不多**——差别全在细节：指纹准不准、字典是不是自己沉淀的。
>
> **AI 能给你通用字典，给不了"你打过的行业里哪些路径真的存在"。** 这个文件只收真实目标上的发现，不收网上抄来的字典。
>
> 规则：每次打真实目标结束后 **10 分钟内**填，不隔夜。记不住就是白打。
