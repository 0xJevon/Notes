## 🎯 核心场景与痛点
介绍某次项目中多个系统打点的思路

## 🧠 攻击链与核心思路
1. 首页存在客服聊天功能点（交互点），通过XSS漏洞获取客服cookie从而未授权登录系统，获取管理员权限。后台图标管理有可通过远程链接获取图标点功能点，通过dnslog测试发现SSRF漏洞（此处还可测试dict协议探测内网信息，或通过gopher协议配合redis写命令获取权限）。
2. 通过弱口令登录后台，在url处发现cmd参数，用于读取base64编码的文件，所以想到任意文件读取漏洞，将要读取的文件路径编码后成功读取文件内容。
3. SpringBoot 1.X RCE漏洞，通过/可访问节点如/env的是1.X版本，通过/actuator路径访问如/actuator/env是2.X版本，RCE主要通过**spring.cloud.bootstrap.location**参数写入存在恶意yml文件的路径，然后通过/refresh接口执行恶意文件从而造成RCE，可在/env中查看命令是否写入
4. 通过JS文件泄露阿里云ak/sk，从而造成云主机接管。阿里云 (Alibaba Cloud) 的 Access Key 开头标识一般是 "`LTAI`"；腾讯云 (Tencent Cloud) 的 Access Key 开头标识一般是 "`AKID`"。
5. 发现sql注入点/student_list.php?cid=，通过布尔盲注可获取数据库数据
6. 可爆破JWT密钥，从而通过修改用户标识造成越权
