# 00 · 红队能力地图

> 目标：从**安全服务工程师**（找到洞、写报告）转为**高级红队工程师**（打穿一条链、达成目标、不被发现）。
> 这条线上唯一的进度指标不是"记了多少"，而是**"能在什么条件下做出什么"**。

---

## 一、验收标准（能力轴，不是知识轴）

达到高级红队，必须能独立做到下面四件事。做不到其中任何一条，就不算。

| # | 验收项 | 当前 |
|---|---|---|
| V1 | 只给一个公司名，8 小时内拿到第一台内网主机的稳定控制权 | ☐ |
| V2 | 从一台普通域内主机出发，24 小时内推到域管（有 EDR 的环境） | ☐ |
| V3 | 全程不触发客户 SOC 的有效告警；若被触发，能指出是哪一步、如何规避 | ☐ |
| V4 | 能把整条链画成图，逐段解释"为什么这么走、还有哪些备选、为什么没选" | ☐ |

自检频率：每月一次。V1→V2 之间通常要 6-12 个月，别急。

## 二、十条能力域（按攻击链分段，不按漏洞类型）

> **为什么不按"SQL注入/XSS/SSRF"分？** 那是安全服务的轴，目标是"找到一个洞交报告"。
> 红队的轴是**链路段**，目标是"在不被发现的前提下推进到目标"。
> 同一个漏洞在两条轴里的地位完全不同：红队只关心它"能不能把入口变成执行权限"。

| 域 | 一句话定义 | 现状 |
|---|---|---|
| **A 侦察与打点** | 从零信息到"可攻击入口清单" | 有 4 篇，偏 Web 侧，缺 OSINT 与资产归属判定 |
| **B 初始访问** | 把入口变成执行权限 | **内容最多**（漏洞攻防/基础入门/6 篇组件漏洞），现有强项 |
| **C 执行与驻留** | 权限落地后活下来 | **空** |
| **D 提权** | 从低权到高权 | 1 篇 3.3KB，偏 Windows 本地提权 |
| **E 横向移动** | 从一台到多台 | 内网安全 41KB + 打靶记录，素材有，缺结构 |
| **F 域渗透** | 从普通域用户到域控 | **空 ← 分水岭** |
| **G C2 与基建** | 让流量活下来 | **空 ← 分水岭** |
| **H 对抗与免杀** | 让行为不被记录 | **空壳 81 字节 ← 分水岭** |
| **I 目标达成与报告** | 证明打穿了 | 安服报告经验可迁移，但红队口径不同 |

**结论一句话**：你的能力集中在 A、B，E 有素材，而 C/D/F/G/H 五个域几乎为零——其中 F/G/H 正是"安服"与"高级红队"的分水岭。

## 三、目录只长不预建

**规则：没有开打的能力域，不建目录。** 空目录会变成"待办墓地"，看着像进度，实际是负债。

├── B-初始访问/
├── D-提权/

├── Z-知识底座/            ← 代码审计/考纲/基础概念，不是作战手册
├── _证据/                 ← 只记实测过的事实

还没建目录的：C、F、G、H、I —— **这是刻意的**，触发条件见下表。

| 域 | 什么时候建目录 |
|---|---|
| C 执行与驻留 | 第一台主机权限稳住后，开始问"重启还在吗" |
| F 域渗透 | 完成 E 的第一条完整横向后 |
| G C2 与基建 | 开始需要"从外网连回内网"时 |
| H 对抗与免杀 | 第一次被 EDR 拦下来时 |
| I 目标达成与报告 | 第一个完整红队项目开始前 |

## 四、第一条链（当前主攻）

起点是**外网单点**，所以第一跳不是去啃域渗透，而是把"单点"变成"有纵深的路径"：

```
外网入口 → 落地执行 → 稳住权限 → 提权 → 抓凭据 → 横向到第二台 → 复盘痕迹
   A/B        C          C        D       D/E        E          E/H
```

**靶场**：Vulnstack 系列（红日），5-10 小时/周 → 一个场景 2 周内跑完。
**产出**：每次跑完必须留下三件东西（见 `02-学习方法.md`），否则算没跑。

为什么不用 HTB Pro Labs / GOAD：那是 V2 阶段的靶场，现在上会变成"跟着 walkthrough 抄"，学不到东西。

## 六、与其他学习线的关系

- **网络基础线**（`Tech/网络基础/`，M0-M18）：是**补短板**，不阻塞主线。只在具体卡住时回补（隧道、代理链、防火墙规则绕过时翻 M0/M11）。
- **代码审计**（`Z-知识底座/代码审计/`）：是**加分项**，不是主路径。红队用它的场景是"打 Java 应用时能自己挖 0day"，等 B 域打透了再说。
- **362 篇面试题库**（`Career/面试题/Sec-Interview-main/`）：**不要读它**。用法是当覆盖度检查表——扫章节名，逐条问"这个点我实测过吗"，答"没有"的就是 `_问题库` 的候选。
