# _证据 · 使用说明

**只收实测过的事实。AI 生成的解释、博客抄来的步骤，一律不入此目录。**

## 命名

```
YYYY-MM-DD-<场景>-<主题>.md
例：2026-11-03-vulnstack1-抓凭据.md
```

## 内容格式

```markdown
## 环境
目标系统 / 权限 / 防护产品版本

## 操作
（原样粘贴命令与终端返回，不改写、不美化、不补全"应该返回"的部分）

## 结果判定
成功 / 失败 / 部分成功 —— 一句话说清

## 异常
与预期不符的地方（这是最有价值的部分，别省）
```

## 铁律

- 命令和输出**原样粘贴**。删掉失败记录的证据层没有价值。
- 一条记录只讲一件事。混在一起就没法被正文精确引用。
- 正文里任何论断都要能指到这里的某一条；指不到的，正文标「待验证」。
