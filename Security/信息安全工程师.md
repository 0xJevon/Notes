## 常见密码算法：
- 对称密钥加密算法
	- DES：**分组加密算法**，采用**移位+替换**，分组长度64bit(位)密钥长度64位，有效密钥长度**56位**（56bit密钥+8bit奇偶检验位）
	- 3DES：密钥长度**112位**
	- IDEA：明文和密文分组都是64位，128bit密钥长度
	- AES：分组长度128位，支持**128、192和256bit密钥长度**，迭代1圈数由密钥长度决定（128对应10轮，192对应12轮，256对应14轮）
	- RC4/5：**流加密算法**，分组和密钥长度都可变，密钥流与明文长度对应
- 非对称密钥加密算法
	- RSA：512位（或1024位），**基于大素数因子分解困难性**，保护网络通信和数据存储的**机密性、完整性、真实性和不可否认性**；**SSH、OpenPGP、S/MIME和SSL/TLS**都依赖于RSA进行加密和数字签名

	- DH、Elgamal、ECC（椭圆曲线算法）：基于离散对数问题困难性

## Hash函数
 Hash函数：杂凑函数、散列函数，将任意长度信息转换为固定长度的hash值
 哈希函数特性：不可逆性、无碰撞性、雪崩效应
 常见Hash算法
- MD5：512位数据块->128bit消息摘要（哈希值）
- SHA-1：512位数据块->160bit哈希值，压缩函数每轮逻辑函数的输出为32位
- SM3：512位数据块->256bit哈希值、
**MAC**(Message Authentication Code,消息认证码)
用单向散列函数的实现，MAC函数用单向hash函数加密时，MAC被称为 **HMAC**(Hash Message Authentication Code)。MAC=Hash (M+key)

Hash能验证数据完整性,**无法进行用户身份认证**,计算过程**无密钥**参与。 
MAC能保证数据完整性,同时可以进行用户身份验证,**有key参与**。可以采用Hash或对称加密算法两 种技术产生MAC值。 
**HMAC是MAC的一种**,可以验证数据完整性,也可以验证数据是由原始发送方发出的,使用hash函数 来构造,HMAC输出长度与Hash长度一样。

- 用于**防止非授权信息等扩散**，从而保证系统的安全，只能保证机密性不能保证完整性
- 具有两种特性：简单安全特性和\*特性
	![[信息安全工程师-20260929-6.png]]

	- 安全级：公开<秘密<机密<绝密
	- 范畴集：安全级的有效领域或信息所归属的领域
Biba完整性模型
- 用于**防止非授权修改系统信息**，从而保证系统信息的完整性

# 访问控制
访问控制：指对资源对象的访问者授权、控制的方法及运行机制
**目标**
- 防止非授权用户进入系统
- 禁止合法用户越权访问
**参考模型**
- 主体（Subject）
- 客体（Object）
- 参考监视器（Reference Monitor），决策单元和执行单元的集合体
- 访问控制数据库
- 审计库
![[信息安全工程师-20261001.png]]
常见的访问控制模型 
- 用于操作系统、数据库系统的资源访问
	- **自主访问控制**
	- **强制访问控制**
	- **基于角色的访问控制（RBAC）**
- 基于属性的访问控制

自主访问控制（Discretionary Access Control，DAC），客体所有者**按自己的安全策略授予系统中的其他用户对其的访问权**
实现方式
- 基于行的自主访问控制：能力表、前缀表、口令 
- 基于列的自主访问控制：保护位、访问控制表ACL

强制访问控制（MAC），根据主体和客体的安全属性，以**强制方式**控制主体对客体的访问，与自主访问控制相比更严格

基于角色的访问控制
包括**用户（U）、角色（R）、会话（S）和权限（P）** 四个基本要素
访问权限与角色相关联，角色再与用户关联

基于属性的访问控制（ABAC）：访问控制方法是根据**主体的属性、客体的属性、环境的条件以及访问控制策略**对主体的请求操作进行授权许可或拒绝

**最小特权原则**指系统中每一个主体只能拥有完成任务所必要的权限集。特权的分配原则是“**按需使用**”，这条原则保证系统不会将权限过多的分配给用户，从而可以限制特权造成的危害。

口令安全管理
口令选择应至少在8个字符以上，应选用大小写字母、数字、特殊字符组合；
禁止使用与账号相同的口令；更换系统默认口令，避免使用默认口令；
限制账号登录次数，建议为3次；禁止共享账号和口令；
口令文件应加密存放，并只有超级用户才能读取；禁止以明文形式在网络上传递口令
口令应有时效机制，保证经常更改，并且禁止重用口令；
对所有的账号运行口令破解工具）检查是否存在弱口令或没有口令的账号。

- 4A系统：认证（Authentication）、授权（Authorization）、账号（Account）和审计（Audit）
- 安全网关
- 系统安全增强：利用**强制访问控制**技术来增强操作系统和数据库系统的安全

# VPN技术
VPN (Virtual Private Network,虚拟专用网）是把需要经过公共网传递的报文（packet）加密处理后，再由公共网络发送到目的地。利用VPN技术能够在**不可信任的公共网络上构建一条专用的安全通道**，经过VPN传输的数据在公共网上具有**保密性**。
VPN安全功能：保密性服务、完整性服务、认证服务。

- 封装安全载荷（Encapsulating Security Payload，ESP）
- Internet密钥交换协议（Internet Key Exchange，IKE）

SSL是**传输层**安全协议，用于构建客户端和服务端之间的安全通道，包含两层协议：
SSL协议分两层，**下层是SSL记录协议**，上层是**SSL握手协议**、**SSL密码规格变更协议**和**SSL报警协议**。
- 下层为**SSL记录协议**：为高层协议提供基本的安全服务，比如**分块、压缩、计算添加HMAC、加密**等。
- 上层为**SSL握手协议、SSL密码变化协议和SSL报警协议**。
	- SSL握手协议（Handshake Protocol)：**认证、协商加密算法和密钥**。
	- SSL密码规格变更协议（Change Cipher Spec）：保客户端和服务器双方应该每隔一段时间改变加密规范。
	- SSL报警协议（Alert protocol)：通信过程中某一方发现任何异常，就需要给对方发送一条警示消息通告。
	![[信息安全工程师-20261002-2.png]]

SSL功能
- **保密性通信**。握手协议产生秘密密钥后才开始加、解密数据。使用对称密码算法。
- **点对点之间的身份认证**。采用非对称密码算法。
- **可靠性通信**。信息传送包含信息完整性校检查，使用有密钥保护的消息认证码MAC。

PPTP：点到点的安全隧道协议，基于UDP1723，主要是给**电话上网**的用户提供**VPN安全服务**。
L2TP：基于UDP1701端口，用于在客户端和服务器直接建立VPN隧道，**不提供加密服务**。
区别
- **PPTP要求互联网络为IP网络**，L2TP可以用于ATM、栈中继等其他网络
- PPTP只能在两端点间建立单一隧道，L2TP支持在两端点间使用多隧道。
- L2TP可以提供**包头压缩**。当压缩包头时，系统开销（overhead）是4个字节，而PPTP是6个字节。
- L2TP可以提供**隧道验证**，而PPTP则不支持隧道验证。
# 入侵检测技术
入侵检测通过**收集操作系统、系统程序、应用程序、网络包等信息，发现系统中违背安全策略或危及系统安全的行为**。
具有入侵检测功能的系统称为入侵检测系统，简称为**IDS**。

早期入侵检测模型根据**审计记录数据**，**生成系统的轮廓**，并检测轮廓的变化，发现入侵行为。
通用入侵检测模型CIDF，把入侵检测系统分成：**事件产生器、事件分析器、响应单元和事件数据**库。
	![[信息安全工程师-20261002-3.png]]

技术原理
- 误用检测：又称基于特征的入侵检测方法，是指根据已知的入侵模式检测入侵行为。
	- **高度依赖特征库，检测不出新的攻击**
- 异常检测
	- **存在较多误报，但可以检测出新的攻击**

入侵检测分类
- 基于主机的入侵检测系统（简称HIDS，收集主机系统等日志文件，分析主机的信息）
- 基于网络的入侵检测系统（简称NIDS，扫描网络通信数据包，侦听网络系统，捕获数据包）
- 分布式入侵检测系统（简称DIDS，多台主机、多个网段采集数据综合分析）

# 应急响应
网络安全应急响应是指为应对网络安全事件，进行**监测、预警、分析**、响1应和恢复等工作。

国家互联网应急中心，简称CNCERT
职责：按照“**积极预防、及时发现**、快速响应、力保恢复”的方针，开展中国互联网上网络安全事件的预防、发现、预警和协调处置等工作，维护中国公共互联网环境的安全，保障关键信息基础设施的安全运行。

中央网信办发布《国家网络安全事件应急预案》，把安全事件分为**恶意程序事件、网络攻击事件、信息破坏事件、信息内容安全事件、设备设施故障、灾害性事件和其他信息安全事件**等7个基本分类。
根据网络安全事件对国家安全、社会秩序、经济建设和公众利益的影响程度，可以将网络安全事件分为四级：**特别重大网络安全事件、重大网络安全事件、较大网络安全事件和一般网络安全事件**。

应急事件处理一般包括**安全事件报警、安全事件确认、启动应急预案、安全事件处理、撰写安全事件报告、应急工作总结**等步骤。

网络安全事件应急演练流程：**制定应急演练工作计划，编写应急演练具体方案，组织实施应急演练方案，最后评估和总结应急演练工作，优化改进应急响应机制及应急预案**。

信息系统灾容恢复等级
- 第1级-基本支持：每周做一次完全数据备份，且备份介质场外存放
- 第2级-备用场地支持：预定时间内调配使用的数据处理设备和通信线路以及相应的网络设备
- 第3级-电子传输和部分设备支持
- 第4级-电子传输及完整设备支持：需配备灾难恢复所需的全部数据处理设备和通信线路及网络设备
- 第5级-实时数据传输及完整设备支持：实现远程数据复制技术，并利用通信网络将关键数据实时复制到备用场地
- 第6级-数据零丢失和远程集群支持：实现数据零丢失，同时要求应用软件是集群的，可以实现实时无缝切换

针对永恒之蓝的应急响应
- 安装免疫工具
- 漏洞修补
- 系统安全加固
- 阻断445端口网络通信
