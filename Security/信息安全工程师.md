# 密码学
《中华人民共和国密码学》与**2020年1月1日**起实施
## 基本概念
![[信息安全工程师-20260922-3.png]]
密钥体制
- 私钥密码体制：对称密码体制
- 公钥密码体制：非对称密码体制
- 混合密码体制：公钥密码体制分配私钥密码体制的密钥
## 常见密码算法：
- 对称密钥加密算法
	- DES：**分组加密算法**，采用**移位+替换**，分组长度64bit(位)密钥长度64位，有效密钥长度**56位**（56bit密钥+8bit奇偶检验位）
	- 3DES：密钥长度**112位**
	- IDEA：明文和密文分组都是64位，128bit密钥长度
	- AES：分组长度128位，支持**128、192和256bit密钥长度**，迭代1圈数由密钥长度决定（128对应10轮，192对应12轮，256对应14轮）
	- RC4/5：**流加密算法**，分组和密钥长度都可变，密钥流与明文长度对应
- 非对称密钥加密算法
	- RSA：512位（或1024位），**基于大素数因子分解困难性**，保护网络通信和数据存储的**机密性、完整性、真实性和不可否认性**；**SSH、OpenPGP、S/MIME和SSL/TLS**都依赖于RSA进行加密和数字签名
	![[信息安全工程师-20260922.png]]
	![[信息安全工程师-20260927-1.png]]
	- DH、Elgamal、ECC（椭圆曲线算法）：基于离散对数问题困难性
- 国产商密
	![[信息安全工程师-20260922-1.png]]
## Hash函数
 Hash函数：杂凑函数，将任意长度信息转换为固定长度的hash值
- MD5：512位数据块->128bit消息摘要（哈希值）
- SHA-1：512位数据块->160bit哈希值，压缩函数每轮逻辑函数的输出为32位
- SM3：512位数据块->256bit哈希值、
## 数字签名
签名者使用私钥对签名数据的杂凑值（消息摘要）做密码运算得到的结果，用于确认带签名数据的完整性、签名者身份的真实性和签名行为的抗抵赖性
- RSA签名体制
- Rabin签名体制
- ElGamal签名体制
## 密码管理
- 密钥管理
	- 密钥生成
	- 密钥存储
	- 密钥分发：人工、自动化和半自动化，自动化主要通过密钥交换协议进行
	- 密钥使用
	- 密钥更新
	- 密钥撤销
	- 密钥备份
	- 密钥恢复
	- 密钥销毁
	- 密钥审计
- 密码管理政策：《中华人民共和国密码法》规定密码分为核心密码、普通密码和商用密码
- 密码测评
密钥分级策略依据密码学中“分层加密”原则，将密钥体系分为主密钥（长期存储，保护密钥加密密钥）、密钥加密密钥（传递会话密钥）和会话密钥（用于数据加密）
## 数字证书
公钥证书（依赖非对称密钥体制），由CA签名的包含公开密钥拥有者信息、公开密钥、签发者信息、有效期以及拓展信息的一种数据结构
![[信息安全工程师-20260922-4.png]]
X.509数字证书内容包括：版本号、序列号、签名算法标识、发行者名称、有效期、主体名称、主体公钥信息、发行者唯一标识符、主体唯一标识符、拓展域、CA签名等。**不包括加密算法标识**
