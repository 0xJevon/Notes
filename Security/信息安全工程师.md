## 常见密码算法：
- 对称密钥加密算法
	- DES：**分组加密算法**，采用**移位+替换**，分组长度64bit(位)密钥长度64位，有效密钥长度**56位**（56bit密钥+8bit奇偶检验位）
	- 3DES：密钥长度**112位**
	- IDEA：明文和密文分组都是64位，128bit密钥长度
	- AES：分组长度128位，支持**128、192和256bit密钥长度**，迭代1圈数由密钥长度决定（128对应10轮，192对应12轮，256对应14轮）
	- RC4/5：**流加密算法**，分组和密钥长度都可变，密钥流与明文长度对应
- 非对称密钥加密算法
	- RSA：512位（或1024位），**基于大素数因子分解困难性**，保护网络通信和数据存储的**机密性、完整性、真实性和不可否认性**；**SSH、OpenPGP、S/MIME和SSL/TLS**都依赖于RSA进行加密和数字签名

	![[信息安全工程师-20260927-1.png]]
	- DH、Elgamal、ECC（椭圆曲线算法）：基于离散对数问题困难性
- 国产商密

## Hash函数
 Hash函数：杂凑函数、散列函数，将任意长度信息转换为固定长度的hash值
 哈希函数特性：不可逆性、无碰撞性、雪崩效应
 常见Hash算法
- MD5：512位数据块->128bit消息摘要（哈希值）
- SHA-1：512位数据块->160bit哈希值，压缩函数每轮逻辑函数的输出为32位
- SM3：512位数据块->256bit哈希值、
**MAC**(Message Authentication Code,消息认证码)
用单向散列函数的实现，MAC函数用单向hash函数加密时，MAC被称为 **HMAC**(Hash Message Authentication Code)。MAC=Hash (M+key)

Hash能验证数据完整性,**无法进行用户身份认证**,计算过程**无密钥**参与。 
MAC能保证数据完整性,同时可以进行用户身份验证,**有key参与**。可以采用Hash或对称加密算法两 种技术产生MAC值。 
**HMAC是MAC的一种**,可以验证数据完整性,也可以验证数据是由原始发送方发出的,使用hash函数 来构造,HMAC输出长度与Hash长度一样。

特性

## 数字证书
公钥证书（依赖非对称密钥体制），由CA签名的包含**公开密钥拥有者信息、公开密钥、签发者信息、有效期以及拓展信息**的一种数据结构
![[信息安全工程师-20260922-4.png]]
X.509数字证书内容包括：版本号、序列号、签名算法标识、发行者名称、有效期、主体名称、主体公钥信息、发行者唯一标识符、主体唯一标识符、拓展域、CA签名等。**不包括加密算法标识**

数字证书按类别可分为**个人证书、机构证书和设备证书**，按用途可分为**签名证书和加密证书**。
更好的管理数字证书,一般是基于PKI技术建立数字证书认证系统(简称CA),CA提供数字证书的**申请、审核、签发、查询、发布以及证书吊销**等全生命周期的管理服务。
数字证书认证系统的构成包括目录服务器、OCSP服务器、注册服务器、签发服务器等。

# 网络安全模型
Bell-LaPadula模型(BLP机密模型）
- 用于**防止非授权信息等扩散**，从而保证系统的安全，只能保证机密性不能保证完整性
- 具有两种特性：简单安全特性和\*特性
	![[信息安全工程师-20260929-6.png]]
- 可用于实现军事安全策略（Military Security Policy），用户要合法读取某信息,当且仅当用户的安全级大于或等于该信息的安全级,并且用户的 访问范畴包含该信息范畴时。
	- 安全级：公开<秘密<机密<绝密
	- 范畴集：安全级的有效领域或信息所归属的领域
Biba完整性模型
- 用于**防止非授权修改系统信息**，从而保证系统信息的完整性
- 具有三种特性：简单安全特性、\*特性和调用特性

# 认证技术
认证由**标识（Identification）和鉴别（Authentiation）** 两部分组成
鉴别的凭据/认证依据：所知道的秘密信息、所拥有的的实物凭证、所具有的生物特征、所表现的行为特征
认证机制由验证对象、认证协议、鉴别实体构成

认证分类
- 认证凭证类型数量：单因素认证、双因素、多因素
- 双方角色和所依赖的外部条件：**单向认证、双向认证、第三方认证**
- 根据认证依据所利用的时间长度：一次性口令（One Time Password，OTP）如S/Key、持续认证

单向认证
- **基于共享密码**：PAP，两次握手认证
- **基于挑战响应**：CHAP，三次握手认证
双向认证：实体双方互相鉴别身份 
第三方认证：通过可信第三方（Trusted Third Party，TTP）实现 

Kerberos协议

- **AS**（Authentication Server），识别用户身份，提供TGS
