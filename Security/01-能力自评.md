## 判定标准（答完由我按这个给反馈）

不看对错数量，看**答案的成因**：

| 表现 | 判定 | 后续动作 |
|---|---|---|
| 结论对 + 理由对（能说清机制） | 已具备 | 直接进下一域 |
| 结论对 + 理由含糊（"一般是这么做的"） | **经验归纳，非机制推导** | 该点要补机制实验 |
| 结论对 + 理由错 | 记忆污染，比不知道更危险 | 优先纠正，容易反复 |
| 只报工具名，说不出前提 | 工具使用者 | 从工具背后的原理重建 |
| 不知道 | 真实缺口 | 排进 `_问题库` 优先级最高的位置 |
