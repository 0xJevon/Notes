# 判别模型清单

> **判别模型 = G07 的第五格，是这套库里唯一 AI 给不了的东西。**
> 前四格（输入空间 / 映射关系 / 适用范围 / 预测目标）AI 一秒给出；第五格问的是"我能不能一眼判断这个场景该不该用这招"——它没有语料。
> 这个清单只做一件事：**把已经在用、但还没写成文字的判别模型，一个一个摆出来，看哪个还缺格子。**

## 二、搬进来时按五格填

| 格 | 要回答什么 | 定级阶梯 | 资产边界 |
|---|---|---|---|
| **输入空间** | 需要什么前提才能用？（数据字段 / 环境 / 版本） | | |
| **映射关系** | 怎么判？**为什么这么判有效**？ | | |
| **适用范围** | 什么情况下它会判错？ | | |
| **预测目标** | 判完能具体得到什么？ | | |
| **判别模型** | 我能不能一眼看出该不该用它？ | | |

> 「适用范围」这一格是分水岭。**第一次填出"不会判错"，说明它还是操作步骤，不是判别模型。**

---

## 三、什么时候算"搬进来了"

三条全过才算：

1. 能说出它**在什么情况下给出错的结论**（通常是第一次答不出，第二次答得出但很勉强，第三次才具体）
2. 别人拿一个没见过的案例来，我能用它在 **3 分钟内**给出结论**和理由**
3. 它能被写成一行：**看到 X → 查 Y → 若 Z 则判 W**

---

## 四、为什么这一步比学新东西更值钱

它只占**整理时间**，不占学习时间，但复用率是全库最高的——**一次提炼，后面所有同类判断都省。**

这与 [[01-脊柱清单]] 是两条腿：
- 脊柱清单（18 个主干问题）负责**发现**新模型——下结论前被哪个问题问住了，那个缺口里通常藏着一个还没成型的判别模型
- 这个清单负责**钉住**已有模型——已有的不钉住，每次判断都要重新想一遍，等于每次都在付一次学费
