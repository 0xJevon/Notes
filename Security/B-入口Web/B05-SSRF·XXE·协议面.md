# B05 · SSRF · XXE · 协议面

> 来源：`00-Web漏洞总览` 按单元拆出（2026-11-20），并核过小迪漏洞攻防笔记（SSRF 重合 69%，CORS/JSONP 为笔记补充）。
> **课程对应**：小迪 D73–79（SSRF / XXE）。
> **判据**：能不能打到内网、能不能读文件、有没有回显。
> 四类的共同点：**利用的是协议栈与浏览器同源策略的边界**——服务端替我去请求（SSRF）、解析器替我读文件（XXE）、浏览器替我发跨域请求（CORS/JSONP）。

## 一、SSRF

### 原理

调用服务器端可访问内网的功能（资源的访问）发起请求

### 利用

利用点：资源调动的功能、涉及URL地址的访问

#### 内网资产探测

借助本地服务器请求访问其下的内网服务器，以获得内网服务器的信息如配置文件、端口开放情况
