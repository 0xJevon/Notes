# B · 入口 · Web

> 把 Web 入口变成可复现的结论。**合同里 35% 的时间在这**，也是唯一要求"自己挖"的一域。
> 源：小迪 D53–117 · 大白哥 5–6。

| B02 | 文件族（上传·包含·下载） | D61–66 | 上传能不能控路径与类型、包含能不能读任意文件 | [[B02-文件族]] |

**单元划分依据**：不按漏洞名，按**判据相同**。上传/包含/下载同判"能不能让服务端按我的路径读写"；RCE/SSTI/变量覆盖同判"字符串有没有被当代码执行"；越权/XSS/CSRF 同判"这个请求该不该被允许"。所以六篇装得下十五类洞。

**不落六单元的**：[[00-打点流程与其余]]——社会工程学、DDOS、资源占用、子域名接管、服务攻防前置、漏洞发现、WAF。流程与外围，不是单点能力。

**现状**：2026-11-20 从原 1 篇 1,917 行「总览」按单元拆成 **6 篇 1,833 行 + 1 篇 194 行**。内容性质没变——**全是速查稿**（原理一句、利用姿势、绕过点），没有一条判据、没有一条实测输出。
**起点**：B04（安服合同里出洞率最高、最不需要工具）→ B01 → B02。

**下一步不是再拆，是改写**：每篇把"绕过点"变成"判据"——每种洞只留三行：**怎么判它存在、怎么判它可利用、判错会怎样**。写完一篇就是一次实测的机会。
