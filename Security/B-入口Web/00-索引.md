# B · 入口 · Web

> 把 Web 入口变成可复现的结论。**合同里 35% 的时间在这**，也是唯一要求"自己挖"的一域。
> 源：小迪 D53–117 · 大白哥 5–6。

| # | 单元 | 关键判据 | 材料 |
|---|---|---|---|
| B01 | SQL 注入 | 参数能不能控、库有什么权限、能不能读文件或执行命令 | [[00-Web漏洞总览]] |
| B02 | 文件族 | 上传能不能控路径与类型、包含能不能读任意文件 | 同上 |
| B03 | 命令与代码执行 | 输入是不是进了系统调用，过滤能不能绕 | 同上 |
| B04 | 认证与会话 | 鉴权写在哪一层、越权是横向还是纵向、JWT/SSO 有没有可伪造 | 同上 |
| B05 | SSRF 与 XXE | 能不能打到内网、能不能读文件、有没有回显 | 同上 |
| B06 | 反序列化 | 有没有可控的序列化入口、链上有没有可用 gadget | [[Security/Java安全/00-索引\|Java安全]] |

**现状**：只有 1 篇速查稿，覆盖 B01–B05 的"有什么"，没有一条判据、没有一条实测输出。
**起点**：B04（安服合同里出洞率最高、最不需要工具）→ B01 → B02。
