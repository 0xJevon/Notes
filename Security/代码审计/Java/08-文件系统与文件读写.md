## Java文件系统安全

- Java中内置两种文件系统
  - java.io
  - sun.nio(java.nio)

### 文件读写方式

#### 阻塞模式java.io.FileSystem

- FileInputStream
- FileInputStream
- RandomAccessFile

#### 非阻塞模式java.nio.file.spi.FileSystemProvider
