## 二之二、另一段源材料：D42–52（Web 开发 · JavaEE）

小迪的 JavaEE 是**先教怎么开发、再教怎么审**（42–52 开发 → 170–184 审计）。那 11 天讲的机制，一半归本目录的"项目形态"，一半归 [[Security/Java安全/00-索引|Java 安全]]，不要重复建单元：

| 天 | 讲什么 | 归哪 |
|---|---|---|
| 42 | Servlet、路由配置、Filter、Listener | 本目录 [[02-项目形态（Servlet·SpringBoot·Maven）]] · [[05-SpringBoot-Web路由与MVC]] |
| 43 | ORM、预编译、JDBC/MyBatis/Hibernate、Maven | 本目录 [[06-MyBatis与SQL审计]] · [[07-JDBC与数据源]] |
| 44–47 | 反射、类加载、动态代理、原生反序列化、JNDI | **Java 安全** 01–14（机制与链） |
| 48 | Log4j、Shiro、Fastjson、XStream 依赖包 | **Java 安全** 15–16；本线只判"引了哪个版本" |
| 49–52 | SpringBoot、模板注入、Actuator/Swagger、JWT、SnakeYaml | 本目录 03–05 + [[11-XXE与JWT]]；链部分在 Java 安全 |
