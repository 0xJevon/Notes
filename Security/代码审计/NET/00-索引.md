## 一、接 .NET 项目先答的问题（开线清单，未验证）

| # | 问题 | 在哪看 |
|---|---|---|
| 1 | WebForms 还是 MVC / Core | 有无 `*.aspx`；有无 `App_Start/RouteConfig.cs`；有无 `Program.cs` + `Startup.cs` |
| 2 | 路由从哪来 | WebForms：文件路径即 URL，`*.ashx`/`*.asmx` 是独立处理程序；MVC：`RouteConfig` 的 `MapRoute` + `[Route]` 特性 |
| 3 | 配置里有什么 | `Web.config` / `appsettings.json`：连接串、`debug`、`customErrors`、`machineKey`、`httpHandlers` |
| 4 | 反序列化入口 | `BinaryFormatter`、`LosFormatter`、`ObjectStateFormatter`、`TypeNameHandling`（Json.NET）、`ViewState` |
| 5 | SQL 怎么写 | `SqlCommand` + 字符串拼接；`EntityFramework` 的 `FromSqlRaw`/`ExecuteSqlRaw` |
| 6 | 上传与文件 | `FileUpload.SaveAs`、`Path.Combine` 未校验、`Server.MapPath` |

**ViewState 与 machineKey 是 .NET 独有面**：`machineKey` 写死在 `Web.config` 里 = 可伪造 ViewState，这是该语言最典型的一条路。
