#### 启动项提权

MySQL 在启动时会读取配置文件（如my.cnf或my.ini），如果攻击者能够修改该配置文件，并重启 MySQL 服务，就可能实现提权。

- **原理**：通过修改配置文件，添加一些具有特殊权限的参数。例如，在 Linux 系统下，添加secure_file_priv=""来放开文件读写限制；或者添加general_log=ON开启通用查询日志，并设置general_log_file为指定文件，然后写入恶意命令，当 MySQL 执行相关操作时，命令就会被执行 。

- **步骤**：首先获取 MySQL 配置文件的写权限，修改配置参数；接着通过某种方式重启 MySQL 服务（如果权限允许直接操作服务，或通过重启服务器间接重启 MySQL）；最后利用修改后的配置执行恶意操作，如使用LOAD DATA INFILE读取或写入文件来获取敏感信息或上传恶意文件。

#### MOF提权

- MOF（Managed Object Format）是一种用于描述 WMI（Windows Management Instrumentation，Windows 管理规范）数据的语言。
- 攻击者利用MySQL的写权限写入MOF恶意文件到`C:\WINDOWS\System32\wbem\MOF`，系统会定期编译执行该目录下的.mof文件，利用该特性便可通过MOF文件执行系统命令从而实现提权
