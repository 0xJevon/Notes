# _项目 · 使用说明

**检验层。** 能力只有在项目里被验证过才算存在。

## 目录

```
_项目/
├── 靶场/       Vulnstack / Vulnhub / HTB / 自建环境
└── 实战/       授权项目（脱敏后放，不留客户可识别信息）
```

## 每个项目的固定产出（四件，缺一不算完成）

| # | 产出 | 说明 |
|---|---|---|
| 1 | **攻击链图** | 从入口到目标的完整路径，每段标出"用了什么、为什么选它" |
| 2 | **卡点时间线** | 每段花了多久、卡在哪、怎么过的（卡住的时间比顺利的部分有价值） |
| 3 | **机制结论** | 3-5 条"下次能直接复用"的判断，每条都指向 `_证据/` |
| 4 | **痕迹清单** | 我留下了什么日志/文件/进程，防御方会在哪一步发现我 |

## 靶场选型（按当前阶段）

| 阶段 | 靶场 | 说明 |
|---|---|---|
| 现在（第一跳） | **Vulnstack 红日 1-5** | 5-10h/周，一个场景 2 周 |
| V2 阶段 | GOAD / HTB Pro Labs | 多域、有防护、要打域控 |
| V3 阶段 | 自建带 EDR 的环境 | 对抗训练，靶场本身不提供对抗 |

**不要跳级。** 直接上 Pro Labs 的结果是跟着 walkthrough 抄，抄完什么都不会。

## 实战项目脱敏

客户名、域名、IP、内部系统名全部替换。**授权范围和时间窗口要留在文件里**——这是合法性的凭证，不是可选项。
