# Java 安全 · 00 索引

> **骨架来源**：小迪安全 V2024-11 第 100–117 天（JAVA 攻防 18 单元，七段）。段与关键词取自原文，编号与状态是我按本库现状补的。
> **一句话**：Java 安全是**研究代码**——一个机制为什么能被利用、链怎么接起来。它回答"能不能打"，不回答"这套业务系统有没有洞"。
> 找业务系统的洞去 [[Security/代码审计/00-索引|代码审计]]。

## 一、与代码审计的分界

| | Java 安全（本目录） | 代码审计 |
|---|---|---|
| 对象 | 机制 / 组件 / 链 | 一套业务系统的源码 |
| 典型问题 | CC 链为什么能从 `readObject` 走到 `exec` | 这个上传点能不能控路径 |
| 产物 | 链路图 + 本地复现环境 | 样本卡 + 复现包 |
| 学习形态 | 可切碎，一个机制一单元 | 必须整块跟源码 |

**两处容易混，规则写死：**

| 混点 | 本目录（研究） | 代码审计（跟踪） |
|---|---|---|
| Shiro / Fastjson | 链怎么接、JDK 卡在哪、怎么绕 | 项目引了哪个版本、从哪个入口触达 |
| 框架（SpringBoot / MVC / Servlet / Struts2） | **不属本目录** | 归代码审计，是审计第 0 步 |

原文的"框架安全"一块（ServletAPI/Struts2/Spring/SpringMVC/SpringBoot），本库 2026-11-13 已整体划给代码审计，理由见 [[Security/代码审计/00-索引]] 第一节。
