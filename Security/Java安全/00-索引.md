# Java 安全 · 00 索引

> **一句话**：Java 安全是**研究代码**——一个机制为什么能被利用、链怎么接起来。它回答"能不能打"，不回答"这套业务系统有没有洞"。
> 找业务系统的洞去 [[Security/代码审计/00-索引|代码审计]]；两边共用证据与问题库，学习时间只能有一条线占（[[Security/04-双线能力线]]）。

---

## 一、与代码审计的分界

| | Java 安全（本目录） | 代码审计 |
|---|---|---|
| 对象 | 机制 / 组件 / 链 | 一套业务系统的源码 |
| 典型问题 | CC 链为什么能从 `readObject` 走到 `exec` | 这个上传点能不能控路径 |
| 产物 | 链路图 + 本地复现环境 | 样本卡 + 复现包 |
| 学习形态 | 可切碎，一个机制一单元 | 必须整块跟源码 |

**框架与项目形态（Servlet/SpringBoot/MVC/Maven）不在本目录**——它们是审计的第 0 步，归代码审计。本目录只碰"语言机制"和"组件利用"。

## 二、路线（按依赖顺序，不是按编号通读）

```
反射与类加载  →  序列化基础  →  URLDNS（最简链）  →  CC 链  →  RMI / JNDI  →  组件（Shiro / Fastjson）
   01              02              03                  04-06      07-08            09-10
```

| # | 篇 | 讲什么 | 前置 | 什么时候翻 |
|---|---|---|---|---|
| 01 | [[01-反射与类加载]] | `Class.forName`、`newInstance`、`setAccessible`、双亲委派 | 无 | **一切链的地基**；看不懂 `getMethod().invoke()` 就先补这个 |
| 02 | [[02-序列化与反序列化基础]] | `ObjectOutputStream`、`readObject`、`serialVersionUID`、为什么有洞 | 01 | 判"这里有没有反序列化"之前 |
| 03 | [[03-反序列化-URLDNS]] | 最简利用链：`HashMap` → `URL.hashCode` → DNS 请求 | 01 02 | **第一次手撕链**；只做带外探测、无回显 |
| 04 | [[04-反序列化-CC1]] | `AnnotationInvocationHandler` + `TransformedMap` 链 | 01-03 | 理解"链"的完整形态 |
| 05 | [[05-反序列化-CC6与CC3]] | 不依赖 JDK 版本的 CC6、动态代理版 CC3 | 04 | 目标环境 JDK 高、CC1 打不通时 |
| 06 | [[06-反序列化-CC2-4-5-7-11与CB]] | 其余 CC 分支 + Commons-Beanutils 链 | 05 | 按目标依赖挑链 |
| 07 | [[07-RMI]] | RMI 三部分（Registry/Server/Client）、九个过程、DGC、攻击面 | 02 | 判反序列化发生在哪一段 |
| 08 | [[08-JNDI注入]] | JNDI 是什么、RMI/Reference/LDAP 三种注入、8u191 后绕过 | 07 | 判 JNDI 是否成立：**协议 + JDK 版本 + 出网** |
| 09 | [[09-组件-Shiro]] | 硬编码 key、rememberMe 反序列化、`anon` 绕过 | 02-06 | 项目里有 `shiro-core` 时 |
| 10 | [[10-组件-Fastjson]] | `@type` 自动类型、版本分界、`JdbcRowSetImpl` 等利用面 | 01 08 | 项目里有 `fastjson` 时 |

> 01 → 03 是唯一必须按序走的一段。04 之后可按目标挑。

**别提前学**：链构造占本目录 2/3 篇幅，但当前主线（安服代审）明确不做。现在翻这些篇只为两件事——判"有没有反序列化入口"、判"组件版本对不对得上"。

## 四、缺口

| 缺口 | 现状 |
|---|---|
| 内存马（Tomcat/Spring） | 无；审计线不做，红队 M3 再说 |
| JRMP / 二次反序列化 | 只在 [[07-RMI]] 提到，未展开 |
| 组件：Log4j2 / Jackson / XStream / SnakeYAML | 无专篇；遇到再建 |
| 本地复现环境 | 无（无 `ysoserial` 使用记录、无靶场证据） |
| 证据 | 本篇 10 篇均为"查阅"性质，`Security/_证据/` 无对应实测 |

**结论**：本目录是**资料库**，不是能力。判断"会了"的标准是能在本地跑通一条链并留下证据——目前 0 条。
