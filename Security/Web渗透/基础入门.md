##### 二次注入

**原理**：在网站一些可写入参数的地方进行sql注入语句时有过滤，但是在注入语句保存在数据库后是正常的，所以要调用（主动/被动调用，比如数据库将注入的语句**更新**）没有过滤的功能模块查询/修改存储的注入语句，导致sql语句被带入查询语句造成sql注入。

例题：[网鼎杯2018]Unfinish

绕过转义/魔术引号：

插入新数据会过滤：insert 1 union select \ '

但是在数据库中会还原：union select '

故数据库更新数据后注入的语句起效  update 1 union select '

1.插入恶意数据

2.引用恶意数据

如在注册用户或修改用户信息时用sql语句插入或更新数据库信息导致信息泄露

### 方法（通过 . 连接各魔术方法（有顺序））

如先返回当前类，再返回当前类的父类（**唯一的（object）**：所以通过base方法找到不变的类），再找父类之下其它可执行python指令的其它子类

类似**无参rce的套娃查询**

如：{''.__ class __ . __ base __ . __ base __}   

异或：{''.__ class __ . __ mro __}   

**包裹**：

‘’or“”：字符 str

（）：元组 tuple

[ ]：    列表 list

{ }：    字典 dict

```python
__class__　　：返回一个实例所属的类（当前类）
__mro__　　  ：返回一个包含对象所继承的基类元组，方法在解析时按照元组的顺序解析。(通过[1]（类似数组）配合subclasses找子类信息)
__bases__　　：以元组形式返回一个类直接所继承的类（可以理解为直接父类）__base__　　 ：和上面的bases大概相同，都是返回当前类所继承的类，即基类，区别是base返回单个，bases返回是元组
// __base__和__mro__都是用来寻找基类的
__subclasses__()　：以列表返回类的子类
__subclasses__()[]：通过数组调用子类
__init__　　 ：类的初始化方法，检查是否重载，即是否可用
__globals__　：对包含函数全局变量的字典的引用，通过列表调用方法
__builtin__&&__builtins__　　：python中可以直接运行一些函数，例如int()，list()等等。同上调用
__dict__　　 ：保存类实例或对象实例的属性变量键值对字典
```

## 反序列化

反序列化发生在涉及数据操作（cookie、session）的功能模块中

反序列化是不触发类的成员方法；只有调用时方法才能触发。

### PHP

魔法方法中出现了一些我们能利用的**函数**，我们就能通过反序列化中对其对象**属性**的操控来实现对这些函数的**操控**，进而达到我们发动**攻击**的目的。

#### 原理

##### 魔术方法

**__wakeup()** 

创建对象时（执行unserialize()）调用这个函数

**__sleep()** 

执行serialize()时，先会调用这个函数

**__construct()**

具有构造函数的类在创建新对象的时候（使用 new 关键字实例化一个对象）,会自动调用该魔术方法（首先调用）

**__destruct()** 

对象被销毁时（回收GC）触发  

unserialize最后自动销毁

**unset**（$obj）主动销毁

**__call()** 

在对象上下文中调用不可访问/不存在的方法时触发（在一个未被定义的函数调用时被触发）

**__callStatic()** 

在静态上下文中调用不可访问的方法时触发

**__get()**

用于从不可访问的属性**取值**或者不存在这个键都会调用此方法

**__set()** 

当对不可访问/不存在的属性进行**赋值**时调用

**__isset()** 

在**不可访问的属性**上调用**isset()**或**empty()**触发

**__unset()** 

在**不可访问的属性**上使用unset()时触发

**__toString()** 

对象被当作字符串使用时触发

(1)echo、print

(2)反序列化对象与字符串连接时（strlower）

(3)反序列化对象参与格式化字符串时

(4)反序列化对象与字符串进行 == 比较时（PHP进行==比较的时候会转换参数类型）

(5)反序列化对象参与格式化SQL语句，绑定参数时

(6)反序列化对象在经过php字符串函数，如 strlen()、addslashes()时

(7)在in_array()方法中，第一个参数是反序列化对象，第二个参数的数组中有**toString返回的字符串的时候**toString会被调用

(8)反序列化的对象作为 class_exists() 的参数的时候

**__invoke()** 

当对象被作为函数调用时触发

**__wakeup绕过**

版本：

 PHP5 < 5.6.25

 PHP7 < 7.0.10

原理：序列化字符串中表示对象属性个数的值大于真实的属性个数时会跳过__wakeup的执行

方法：增大对象属性个数的值

- Minikatz

当系统为win10或者2012R2以上，内存中默认禁止缓存明文密码

可通过修改注册表的方式进行抓取，但需重启后重新登录时才能抓取。

windows 2012以上默认关闭了Wdigest，所以攻击者无法通过内存获取到明文密码

为了针对以上情况 所以有四种方法解决：

1.利用（PTH,PTK）等进行移动不需要明文

2.利用其他服务协议（SMB/WMI等进行哈希移动）

3.利用注册表开启（wdigest auth）进行获取、

4.利用工具或者第三方平台（HASHCAT进行破解获取）
