# 00 · 能力地图（攻防兼备的高级渗透测试工程师）

> **定位（2026-11-18 第二次修正）**：主交付是**渗透测试合同**（含内网到域控），副交付是**代码审计专项**，能力上保留红队纵深（免杀、权限维持、域内路径）作为溢价项。
> 上一版把"隐蔽/维持/极限深度"整块砍掉是错的——砍的应该是**自研兵器那一段**，不是能力维度本身。
> 课程来源：[[05-课程映射与学习顺序]] · 里程碑：[[03-学习计划]] · 代审线：[[10-代审支线]]

## 一、验收标准（Q1–Q5，做不到就不算会）

| # | 验收项 | 判定方法 |
|---|---|---|
| **Q1** | **覆盖完整**：资产清单齐全，每项标产权归属与边界 | 对照合同范围逐项勾；列出剔除清单及理由 |
| **Q2** | **结论可复现**：每条漏洞有最小复测包，第二人按包能复现 | 交付前请第二人复测一次 |
| **Q3** | **定级站得住**：三轴取值清楚，能指到证据原文 | 抽查 3 条，指不到即降级 |
| **Q4** | **纵深到位**：该走到主机的走到主机，该到域控的到域控，不半途交差 | 项目结束后对照合同范围，标出"该到未到"的节点 |
| **Q5** | **边界清楚**：能说出"这次没覆盖什么、为什么" | 报告里必须有覆盖率与未覆盖说明 |

> Q1/Q2/Q3/Q5 是安服的验收；**Q4 是红队纵深留下的那一条**——它不要求"不被发现"，但要求"真的走到了"。

## 三、深度分级（哪些保留、保留到哪）

| 维度 | 顶级红队 | **本库要求** | 明确不做 |
|---|---|---|---|
| 免杀 | 对抗 EDR、长期不被发现 | **过主流杀软稳定上线；EDR 会绕，靠 AI 改写 loader** | 自研加载器、驱动对抗、C2 二开改特征 |
| 权限维持 | 多后门、隐蔽持久化 | **Web / 服务·计划任务 / 票据 三类够用** | 隐蔽通道、固件级 |
| 域渗透 | 委派武器化、RBCD、ADCS 全套、信任域 | **能独立走到域控，常见路径各会一条** | 信任域、跨林、Exchange 链 |
| C2 | 自建、魔改 | **会用成熟框架，看得懂配置** | 自建基建 |
| 痕迹 | 对抗取证 | **知道自己留了什么**（反向：安服要留证据） | 日志篡改、时间戳伪造 |

**判断标准一句话**：这条能力**会不会在某次合同或演练里被真的用到**。会用到就留，留到"能独立做完"为止。

## 四、AI 在六域里各接什么（横切，不单独排期）

**判据只有一条：AI 放大的是重复劳动与覆盖度，不是判断。** 每一域都有一半工作是可以交给 Agent 的，另一半不能。

| 域 | AI 能接住的（练到能稳定跑） | 必须自己做（AI 给的是候选，不是结论） |
|---|---|---|
| **A 资产与暴露面** | 子域枚举去重、指纹批量比对、企业产权初查、台账生成 | 判"这台在不在测试范围" |
| **B 入口 · Web** | 请求变体生成、响应差异比对、编码绕过批量试、参数点定位 | 判"这里能不能控变量、控了有没有用" |
| **C 组件与边界** | 版本→CVE 匹配、EXP 适配改写、指纹库维护、提示词变体批量试 | 判"前置条件够不够、会不会把服务打挂"、判"AI 应用里说错话还是做错事" |
| **D 提权上线维持** | 枚举输出解析、提权路径排序、loader 改写与免杀迭代 | 判"缺哪个权限就卡住" |
| **E 内网与域** | 收集结果结构化、路径图生成、命令变体、票据字段解析 | 判"这一跳会不会触发告警、影响生产" |
| **F 验证定级交付** | 报文清洗、证据与表述逐条核对、报告初稿、定级口径自查 | 判"这条值不值钱、定几级" |

**落法**：每个阶段（S0–S7）收尾时，把这一段里最耗时的重复动作包成一个 tool 或一份 SKILL.md，进 `Security/工具链/`。**不单独排"学 AI"的周次**——它跟着真实任务长，才有东西可约束。

**这条线的完成标准**：不是"会用某个 Agent 产品"，是**你的 SKILL.md 里写着红线，Agent 撞线时会停**。

## 五、明确不做（做了就是浪费时间）

1. **自研兵器**——Go/Nim 写加载器、C2 二开、驱动对抗。那是产品线，不是能力维度
2. **非约束/约束委派武器化、RBCD、ADCS 全套**——留一条能走通的路径即可
3. **信任域、跨林、Exchange 攻击链**——合同基本不覆盖
4. **红队 APT / 钓鱼 / 近源**——不在渗透合同范围
5. **Web3 / CTF / 面试话术**——与交付无关
6. **七语言全覆盖**——Java/PHP/.NET 读到能改，其余读到能认
7. **长期驻留与隐蔽通道**——安服反向要求可追溯
8. **自己搭 Agent 平台 / 训模型**——用现成的，你的活是写规矩不是写框架

## 六、时间预算（每周 20h，年约 1000h）

| 块 | 小时 | 说明 |
|---|---|---|
| 根基轮转 | 110 | HTTP / 权限模型 / 序列化 / 日志，每季度回一次 |
| Web 与业务逻辑 | 200 | 合同主体 |
| 代码审计 | 200 | Java 为主，PHP/.NET 各留 40 |
| 内网到域控 | 220 | 打点→提权→横向→域内路径 |
| 免杀与维持 | 90 | **靠 AI 改写 loader 提效，不啃汇编** |
| **AI 编排与交付** | **180** | 从上一版 60 上调：T01–T06 要能稳定跑，不是会用 |

> 上调的 120 小时全部从"Web 与业务逻辑""内网到域控"里挪，理由是：那两块你已经有一半底子，而"指挥 AI 干活"是新的、且**决定你未来三年效率上限**的一项。
