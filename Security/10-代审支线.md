# 10 · 代审支线（代码审计）

> **定位**：一条支线，**跟着项目时间走，不占主线的 29 周**。主线是六域（[[00-能力地图]]），它占学习时间；这一条占工作时间。
> **终点**：给一套没见过的系统，独立完成「入口 → 链 → 判定 → 复现 → 定级 → 报告」，并说清没审哪些面。
> 上位：[[04-三线分工]] · 骨架：[[Security/代码审计/00-索引|代码审计索引]]

---

## 一、验收（A1–A4，做不到就不算）

| # | 验收项 | 判定方法 | 不过怎么办 |
|---|---|---|---|
| **A1** | 4 小时内对一套系统给出 3 条带 `文件:行号` 的候选，其中 1 条能出可粘贴的复现请求 | 计时 + 第二人按行号复现 | 回入口建模（Java 索引组一） |
| **A2** | 每条候选五列齐全：入口 / 链 / sink / 拦截 / 实测 | 缺一列即判未完成 | 回数据流 |
| **A3** | 每条进报告的条目有三轴取值，且能指到 `_证据/` 的原文 | 抽查 3 条，指不到即降级为候选 | 回 F 域 |
| **A4** | 能说出覆盖率：共多少入口、审了多少、剩多少及原因 | 对照 `routes.json` / 索引表 | 回入口建模 |

> 连续两套系统 A1–A4 全过 = 这条支线转"按项目维护"，不再排周计划。

## 二、6 周排期（8–10 h/周，70% 动手）

| 周 | 焦点（只一个） | 练什么 | 产出 | Gate |
|---|---|---|---|---|
| **W1** | 入口建模与鉴权 | MCMS（Java/Shiro）+ 一个 PHP 开源 | 入口卡 2 张 + 判定卡 2 张 | 列出 ≥20 个入口，对其中 3 个说出"匿名/需登录"及依据行号 |
| **W2** | SQL 注入全链 | MCMS 两处 + PHP 一处 | 样本卡 4 张 | 1 条布尔/报错注入可复现；1 条"被过滤"能说明挡不挡得住 |
| **W3** | 文件操作族 | 任选 OA/博客/商城，六类各找 1 处 | 样本卡 6 张 + 证据 2 份 | 3 类能出可粘贴请求；另 3 类能说出不成立条件 |
| **W4** | 命令/代码执行与解析类 | MCMS FreeMarker + PHP 文件包含/SSRF | 样本卡 4 张 | 1 条走到命令/模板执行；另 1 条 SSRF/XXE 有外带或回显 |
| **W5** | 组件漏洞（只判前置） | Shiro / FastJSON / Log4j2 | 组件卡 3 张 | "版本→前置→可控入口"三步能独立写全，缺一步能说缺哪步 |
| **W6** | 完整系统 + 交付 | 若依 / MCMS / 华夏 ERP 任选一套 | 报告骨架 + 覆盖率表 + 样本卡 8 张 | **A1–A4 全部通过** |

**每周最低配额**：4 张样本卡 + 1 张判定卡 + 1 份证据。连续两周达不到 → 本周不换焦点，先补卡。

## 三、从"洞"到"作战"的三条判断

这是代审线唯一通向主线的地方。审出一个洞之后，多问三句——答得出，它就能直接喂给 B/D/E 三域：

| # | 问什么 | 答不出说明 |
|---|---|---|
| **1** | **能不能落地执行**：数据源可控 / 有可用原语或组件 / 权限与路径够 | 它只是"存在"，不是"能用" |
| **2** | **落地之后下一步是什么**：本机凭据在哪、能不能复用、该提权还是该横向 | 洞的价值止于一条报告条目 |
| **3** | **防守方在哪看得见**：≥2 个可见信号（日志字段 / 文件 / 网络），规避代价多少 | 你不知道自己的动作有多响 |

> 三句话分别对应主线的 D（上线）、E（横向）、F（痕迹与复测）。写在样本卡第 6 节，不另建卡。

## 四、明确不做

1. **反序列化链构造**（CC/CB 手撕与改造）——属 Java 安全，链构造是 M2–M3 的事
2. **内存马**（Tomcat/Spring）——交付与代审判断都不要求
3. **XSS/CSRF 的利用细节**——只留"判定一句话"，不进样本卡
4. **CVE 清单**——只对本地依赖文件里出现的版本做匹配，不建全量库
5. **把课程/文章的步骤抄成笔记**——G16 禁入，只允许写"我跑通的"

## 五、纪律

1. 卡点**当场写**，不隔夜（隔夜回忆是重构过的）。
2. 问题四样：现象 / 我的猜测 / 实验设计 / 关闭条件；缺一样不建（G15）。
3. `待验证` 超过 15 条 → 停新输入，先清队列。
4. 同一卡点出现第 3 次 → 停，换环境或换焦点（G22）。
5. **到期未过就砍目标**（8 张/周降到 4 张/周），不延长周期。
